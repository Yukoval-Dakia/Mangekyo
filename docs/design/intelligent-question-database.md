# 智能题库的选题依据与自治规则

智能题库（Intelligent Question Database）服务于一个具体决定：此刻给这个学生看哪道题，收到什么回答以后，值得改变下一步？每道题都要说清它适合教什么、能区分哪些解释，以及什么结论超出了这道题的能力。

## 一道题要保存哪些内容

以可以独立发给学生的一版题为单位。保存原件出处与允许用途、完整题干、图表、共享材料和子题之间的依赖。解答包括已核验的解法、合理的等价答案、部分得分依据、从轻到重的提示，以及一道尽可能短的辨别题。学校原卷的评分说明和系统补拟的说明各自注明出处。

交互题同时保存那一版图、变量范围、提交动作和揭示规则。例如速度图可以在讲解中随拖动显示均值，在独立检查中则等学生提交预测后才显示。发题时固定题面、呈现方式与判分约定，复核时能还原学生实际看到的内容。

## 语义标签怎样做到精确

把观察目标、完成任务所需的先修能力、可选解法分开标。例如一道匀速分段题的目标是按时间合成速度，单位换算可能是先修，用速度图求面积只是可选路径。每项重要标签都能指向题干中的条件、图中某段、解答中的一步或一个反例，并保留来源、适用范围、版本与核验状态。

题目还要标明表征、关键条件、容易混淆的方法和区分解释所需的最小改变。例如两个速度各走一小时，直接平均与按时间加权都给出 45。这个题面允许观察数值作答，却无法单凭 45 识别学生用了哪种方法。把后一段改成两小时，两种预测才分开。干扰项可提示要核查的错因，学生选中它本身只是一条线索。

## 变式和接触史怎样影响使用

题与题可以来自同一原件、互为译本、只换了数字、只改了一个关键条件，或要求把同一关系迁移到图、表、文字等另一种表征。每条关系说明保留了什么、改变了什么，以及会不会提前透露下一题的做法。换数字的题可以用于练熟，首次迁移则需要一组真正独立的材料。

题库维护可复用的内容。对某个学生发过哪一版、看过哪阶提示、是否见过同族题的完整解法、原来交了什么，均属于带用途范围的活动记录。选题时才合读两边。学习者模型引用允许使用的作答证据作判断，Agent 的选题理由可以复查，同一次判断不能充当它自身的验证。[记忆与认知设计 R0](https://chatgpt.com/space/page_ee2e701994ac8191949206edcaf43413)

## Agent 怎样找题与补题

Agent 可以提出教学请求，例如“三分钟内完成，能区分直接平均与按时间加权，只改变一个条件，学生没见过同族解法”。检索先应用用途、时间与接触限制，再按语义关系找候选。Agent 打开实际题面与解答，记录选用的依据，也记下与决定有关的淘汰理由。学生能展开查看“为什么今天问这个”。

检索正常但没有合适题时，说明缺在哪个条件，例如“现有三题里两题无法区分这两种方法，另一题昨天已揭示解法”。检索失败则保留失败与待重试状态。教研 Agent 可根据具体缺口生成候选，经独立求解、对照反例、查重及用途核验，再进入可供发放的题目。

## 题库怎样自我治理

Agent 可以发现重复题、提议合并同义标签或拆开含混标签、标出答案冲突、安排复验。变更保留依据、影响对象与可撤回的版本。争议定位到具体用途，例如暂缓用某题区分两种方法，同时保留它作等时段的讲解例题。修正答案或撤回标签时，沿引用找到受影响的判分、学情和备卷，按影响重算，原发题与原提交仍按当时的版本回看。

预计用时、难度与辨别能力先注明是估计，再用真实作答校准。把独立完成、看提示后完成和在新题上的迁移分开。一个学生连续做对可以调整对他下次用时的预期；若要声称题目对一类学生有区分度，还需相应范围的证据。样本不足时保留未知。

## 首项验收 同一个45 两份不同的学习史

两位学习者都对“30 与 60 公里/小时各走一小时”答了 45。甲此前在未见解答的不等时题上写出过总路程除以总时间，乙此前只在等时题上给过数值。发出同一题后，让真实 Agent 展示它实际读取的版本、历史作答与提示曝光。若甲的证据仍适用，允许跳过重复追问。对乙，可只把第二段改为两小时，正确结果变成 50，直接平均仍是 45。

继续验收回答后的分支。乙若用 150 公里除以 3 小时说明 50，转往另一种表征；若仍答 45，先请他写出两段各走多少公里；若只答 50，保留方法未知。再分别加入已看过该变式解答的记录、移走最后一道合格变式，检查 Agent 能否识别曝光、报告真实缺口，并说明下一步。这里验收的是可追溯的选题与调整，具体措辞可由 Agent 自行决定。
