# 学习者雷达的在途抽取

`read_context({intent:"radar"})` 新鲜读取返回 `in_flight_todos`。当前视点最多显示一条获准的个性化抽取，格式为 `{"state":"available","item":{"kind":"personalized_extractor","state":"ready"}}`。在途状态取工作账本的 `pending`、`ready` 或 `waiting`。`ready` 表示已登记派发，不承诺正在执行。没有可证明的当前项时返回 `{"state":"unknown"}`。其他 Todo 类别和学科、知识点范围暂时没有可用投影。既有雷达字段、工具和 Python handle 沿用原契约。

只有正式完成、本人显式同意后台理解的同伴回合可作为来源。源事实须保持研究和教学用途，来源回合记录的教学模型、账户和工作区授权须与本轮接收方相符。后台 Worker 接收方的授权独立判断。雷达仅发布固定类别和工作状态，正文、来源和 Work 标识、授权代次、费用及错误留在受保护的内部读取链。

同一次读取保存 Work 的修订、代次和状态、教研设置见证、源事实版本与访问代次以及接收方。恢复工具步、发送工具结果、发布引用该结果的回复和重用回复均复验。依据变化后，旧读取或回复停止重放，当前视图重新按可证明范围返回。工作只读来自 PG 领域账本，Temporal 仍负责实际执行和恢复。
