# 教学载荷随材料擦除

D06 的确认入口仍是 `POST /api/materials/:id/erasure`。在原件的学习者锁内解析原件及配对事实，沿现有 Work 发布关系收集擦除根。物理清除本次根所支持的教学缓存、传输回执、回复正文和进行中的回复草稿。正式材料外的独立答卷、同伴原话、外部副本和离线备份沿用原范围。

依赖通过已保存的身份确定。工具回执按已授权的来源见证，教学派生按 manifest 事实和精确 slot 版本，附件按提交中记录的材料身份。后续回合只在确实使用受影响回复时纳入。按学习者和教学槽限定清除边界，保留自己输入、独立采纳的内容以及无关回合。混合来源回复的整份正文清除，保留无正文的已结算位置。历史派生也在匹配范围。拒绝用途与确认擦除继续使用各自入口。

对进行中的回合，发前持同一学习者锁复验并登记当前 Work 用到的来源，复用工作来源列和代次。材料擦除原子移除精确回合载荷并使其活动代次失效。已完成的模型步骤和已预订的费用仍由既有效果归档按原身份结算。恢复只能取得内容为空的归档或明确失效状态，不能把清空的本地收据当成一个新的已授权工具调用。已经送达前台模型的内容只验证后续不再发送，外部接收方的副本仍属原有 D06 范围。

优先使用现有 Work 来源索引和同一学习者内的已存见证。范围按确实存在的来源和回合依赖求闭包。遍历用集合去重，既不以正文相似性猜测，也不以固定深度截断。无需新表、持久索引或迁移即可尝试正式材料与已存教学载荷的窄修。若见证不完整或实际计划无法把扫描约束到同一学习者的相关入口，先交现象和最小持久设计。历史已经完成的擦除请求不在本轮补删范围。

验收使用合成材料的实际 HTTP 上传、教学读取和擦除。记录擦除前后 PG 正文、同键回执重放、同一会话发出的前台请求、已发请求的迟到返回、无关回合及费用身份。确认擦除和无关回合分别做阴阳性。正式入口和测试用隔离 schema 保持现有授权边界。

固定复审的 5,050 条无关历史样本中，改用 JSON 包含条件仍需逐行检查。追加一条前向索引迁移，使用 `(manifest->'inputs') jsonb_path_ops`，覆盖存量与新增派生的事实、精确 slot 及 range 成员见证。根和命中派生按 learner 及身份反查，只有命中的派生继续扩展。显式种子按教学槽精确查历史，流式草稿和旧工具回执保留原检查。索引只涉及现有数据，不创建另一份权限或正文快照。
