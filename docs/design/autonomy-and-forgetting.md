2026-11-19。四级自治与自研遗忘是已定产品规范。写入归属、引用与接线沿用[统一数据流转契约](data-flow-schema.md)和[产品共享合同](product-contracts.md)。下文的验收反例供各支线接入时验证。

## 四级自治

| 级别 | 生效与呈现 |
| --- | --- |
| **0 · 静默生效** | 推导题目统计，独立重做变式并核验反例，登记有据的语义边与去重关系，更新「今天」的观察和可调整安排。推断边先留在槽位，核证后才由 `content` 命令确认。去重保留各原件、ID 和作者，同一原答的多份转述只计一次，两次真实提交各自计证。安排保护锁定、进行中及已完成项。 |
| **1 · 先做，可撤回** | 在已有授权内维护本人未编辑过的教材块，处理交入后的明确拆题与归档，试用有范围和期限的软偏好。各次写入保留版本与回执，在结果处一键撤回。本人声明由 `learner` 持有，推断的软偏好存为 `companion` 可更正记忆，服从本人声明。 |
| **2 · 就地采纳或拒绝** | 把采纳和拒绝放进发卷、改作答、整理等相关操作，或在受本人编辑保护的 sticky 页显示逐块差异。打开该处才出现，首页无卡片、角标或审批队列。「今天」聚合可保留关联引用，展示的仍是可直接进行的学习活动。 |
| **3 · 明确拍板** | 战略路线分叉、私密数据外发的授权、设置或提高费用上限、不可逆操作须由本人确认具体影响及适用范围。已批准的外发范围和额度内按原授权执行，适用目的、接收方或额度超出时等待新决定。已有拒绝、未知用途或不符留存条件时阻断执行。 |

同一意图取最高风险，低级动作中夹带任一第 3 级效果，按第 3 级处理。例行换题仍由 `plan.today` 决定，改变目标承诺由本人拍板。用户拒绝按目标和意图生效，重算、换措辞、跨日和换模型沿用该决定，只有本人重开或其选定的解除条件满足才再提。见[目标与节奏](../product-spec.md#d05)、[数据自主](../product-spec.md#d06)和[低打扰与费用](../product-spec.md#d07)。

**写入与采纳。** UI、生成作品宿主和 Agent 走同一内核入口。命令唯一写事实，内核唯一接受推导。内核按命令声明和实际效果核对级别，并在学习者事务中复核输入清单、用途和工作代次。需独立身份的产物通过 `adopt` 映射为所有者命令，事务内写版本或提议并返回回执。第 2、3 级由现有提议承载，确认时重验目标基版本、来源和授权，拒绝只记录决定。事实、命令、推导器和块足以表达上述行为。见[内核的采纳与撤销](../kernel-design.md#8-采纳提议撤销)。

**编辑、撤回与历史。** sticky 随学习者的块级编辑血缘保留，移块、换页或重新生成不得绕过保护。撤回走 `undo(command_id)`，整批目标仍是原命令所写版本且用途和 sticky 未变化才追加逆向修订，否则整批冲突，保留双方草稿。迟回执只确认对应编辑。旧采纳重放复用原回执，刷新、重算和续跑均须尊重撤回与拒绝，不能换新命令身份自动复活同一变更。历史中的已发题、归档、原判和旧推导可按固定版本及获准用途回看。失效或撤回的依据标明状态，不能支撑新的生效结果。已发生的作答、实际曝光和外部效果各自保留事实或账本状态，撤回教材也不会抹掉曾看过的答案。

**撤权。** 固定版和历史同样核对本人作用域、当前及历史用途、原始依赖和删除凭据。每次打开、外发、写入和接受都复核。用途收窄、撤回及重授推进 `accessEpoch`，使依赖失效，旧缓存、摘要、候选和恢复中的 Worker 不能沿用旧读见证，重授须重新读和采样。`turn_only` 在本轮后只供本人回看，`ephemeral` 到期销毁正文。永久删除优先于历史与 undo，恢复前应用独立防回退凭据。见[数据生命周期](../adr/0008-data-lifecycle-and-erasure.md)。

## 掌握、保持与对账

采用自研、具名且版本化的保持推导，排除 FSRS。`learner.mastery` 描述知识点上有证据的能力及不确定性，独立于保持算法。保持推导描述指定时间和条件下仍能提取或完成的可能性，接口独立于具体算法，保存可序列化状态并按读取时刻呈现。更换保持方法无需改写掌握证据。`plan.today` 用两者及约束安排复习和探测。仅同题无提示答对可支持该题保持，跨情境掌握还须适用的独立过程证据。受助正答、见过答案、仅自评或看完教材均不能记为独立掌握，缺证保持未知。

`learner` 的 `predict.forecast` 在目标活动结果发生前冻结目标及可比条件、预测值或未知、发出时间、截止条件、方法版、固定输入清单和 learner clock 水位。`predict.reconciliation` 固定原预测，跟随获准的事后真实提交、评估、更正和实际曝光。以发生时刻判断是否为窗口内的事后学习，以内核 tick 确定该次对账看得到哪些证据。实际剧透标污染，缺独立后测标待观察。迟到证据或误判复核产生新对账版，保留原预测和先前对账。已纳入成员失效走 `stale`，后增有效成员按既有截至语义标 `behind`。

Temporal shadow 以同一批预测时输入和获准后测、同一观察水位、同一纳入条件对照具名方法，报告覆盖、校准误差、污染及缺项。重放不把晚收到的观察补进原预测输入，历史拟合单列。影子候选不进入生产 `current` 或范围成员，不写学习事实、不触发采纳或排程。Temporal 负责执行和恢复，PostgreSQL 的内核仍负责领域接受。生产切换靠显式方法版本配置，可切回并保留旧版本与依据。见[工作单元 15、16、24、40](../BACKLOG.md)。

## 字段与所有者

| 字段或见证 | 所有者与语义 |
| --- | --- |
| `occurredAt`、`receivedAt`、观察水位 | `activity` 等事件所有者声明实际发生时间，内核记录服务端首次接收时间。产品字段分别映射到内核 `occurred_at`、`recorded_at`，重放保留两者。水位使用 learner clock 的 tick，离线迟到不倒排因果。 |
| 语义边、`variant_of`、`familyId`、`spoilsNext` | `content` 持有类型、方向、端点、范围、来源和核验状态，记录变式保留与改变的条件及单向剧透。同源去重和新颖度分类沿这些引用，可区分原题、同族变式、新表征与新情境。 |
| 实际曝光阶次、独立性、过程质量 | `activity` 持有发放、原答、帮助内容版与实际展示回执，记录提示阶次、影响题项和内核刻度。准备、请求与送达分开，可靠未曝光与无法观测分别记。`activity` 的评估和过程槽位依据冻结规则及相应轨迹输出质量与独立性，`learner` 按适用性取证。 |
| 教材 `author`、块级 diff 血缘 | `content` 在稳定页与块 ID 的修订上保留 `learner / companion / research` 的编辑归属、基版本、前驱块修订、分项 diff 和来源引用，执行者、采纳来源与命令回执仍由原契约记录。自动采纳或移块保留本人编辑的保护。 |
| Generative UI 预测锚点、揭晓动作回执 | `content` 的作品固定版声明预测作答位及稳定对象、动作 ID。`activity` 把学习者事先提交的预测固定到该锚点、发放和作答位，适用时另连 `learner` 的事前 forecast。宿主核验基版本和动作身份后走 `activity` 命令，回执关联揭晓条件、作品版及影响范围。答案获准后才下发，实际展示才记曝光，重试同一动作复用回执。 |
| `learner.feedback` | 共用读投影，按原所有者链接提议接受/拒绝、本人编辑、OCR 更正和评估申诉/复核的事实与回执。带来源和适用范围地汇入对账与校准，区分产品误判、选择偏好和真实学习结果。仅收到申诉不改正式评估，拒绝建议也不算能力下降。 |

## 受影响支线与验收反例

以下接线沿用数据流契约 Wave A–C。旧记录沿授权适配读取，缺字段显示未知。

| 支线 | 采用、保留兼容、后补 | 正常入口的反例 |
| --- | --- | --- |
| A1/A2 与 Agent 宿主、Temporal coordinator | 采用默认 storage、单命令/accept 与工作代次。保留旧密钥作用域和已结算回执。后补后台越级控制及 Wave C shadow。 | 把私密原图外发夹在第 0 级去重里，无确认时无出站。收窄用途后恢复旧流程，旧候选拒绝，未知收费保留占额。 |
| A4–A6 原答与 rubric、交入全文、组卷血缘和 assessment | 采用有据拆题、冻结发放及共用的正式评估读路径。保留旧卷、来源版本和历史评估。后补存量契约核验与申诉反馈。 | 从原图把 D 更正为 B，只重判受影响项。改题库标答后历史卷仍按原规则打开，撤权后旧草稿不能凭复制内容发布。 |
| Wave B 教材 revision/write-set、编辑器与后台讲义 | 采用块级作者、差异和第 1/2 级。保留旧页和课堂归档引用。后补逐块接受、拒绝、undo 与冲突接线。 | 本人改块后后台结果只在该页出现。拒绝后换词不再出现。撤回后重连旧设备或重放旧命令，块不复活。并发改动时整批撤回冲突。 |
| A7 RecallCard、help exposure 与 Generative UI 宿主 | 采用冻结预测锚点、发放和揭晓回执。保留旧活动与作品挂载。后补曝光阶次、过程质量与事后对账。 | 刷新、提前请求答案或只拖动控件不产生曝光或正式提交。独立正答、看解答后同分、无见证三例分别落证。后题被前题剧透时不能充作独立迁移。 |
| A3/A8 与 Wave B/C 图谱、选题、偏好、记忆和「今天」 | 采用有据语义边及已声明偏好优先。保留旧边与旧路由备忘的授权读取。后补家族新颖度、保持、对账和反馈校准。 | 同得 45，一人有独立列式，一人只看过例题，实际换题依据应不同。撤回软偏好后重启不恢复，锁定项不移动，第 2 级提议不进首页。离线迟到的后测可以更新对账，原预测固定，shadow 结果不改变生产选题。 |
