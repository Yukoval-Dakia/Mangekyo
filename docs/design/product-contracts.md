## 共享事实与调用路径

| 所有者 | 持有的事实与推导 | 学生与同伴从哪里使用 |
| --- | --- | --- |
| `capture` | 原件、交入关系、原件修订和页区。抽取和歧义定位由推导产出。 | 四处交入并取得收件回执，从「材料」或复盘打开原件、补页、确认识别。 |
| `content` | 题版、评估规则、作品与教材块、学科语境、方法模板、知识关系及跨版映射。解法核验、草稿和检索索引由推导产出。 | 从「材料」、课堂、卷或同伴打开原版，找题、开练、修订和分项采纳。 |
| `activity` | 发放、课堂实际编排与归档、作答草稿、实际提交与过程、帮助曝光、自评和申诉。正式评估、过程质量和错因属于槽位。 | 在线开练、课中检查、纸卷拍回和作品上传共用活动提交语义。复盘可更正、查看判分依据和请求复核。 |
| `learner` | 本人声明、偏好和控制配置。能力、保持、误解、事前预测和对账属于有证据的推导。 | 在「我」查看判断和原作、管理声明和设置。同伴在获准的任务中使用。 |
| `plan` | 目标、学校进度、可用时间和锁定项。安排和备课需求是推导。 | 在「我」调整约束，在「今天」开始、换选、延后或休息。同伴可提出有依据的调整。 |
| `companion` | 会话、人格、工作单和有独立身份的记忆条目。摘要、召回和整理候选是推导。 | 题下、课堂、阅读和自由对话中的同一个同伴，及「我」的记忆与后台状态。 |
| 内核与执行环境 | 内核持有命令回执、输入清单、访问与删除代次、工作意图、outbox 和效果账本。Temporal 持有执行进度、等待、取消与恢复。 | 界面与同伴共用内核生成的命令和槽位入口，提交状态、进度与成果都可沿回执重开。 |

跨域使用所有者的公开类型和引用。一次正常调用由界面动作或会话工具提交意图，内核核权、执行领域命令并返回回执，需要计算时由所属推导器交候选，内核接受后由块呈现。命令唯一写事实，内核唯一接受推导。相同命令身份与输入返回原回执，相同身份换载荷返回冲突。投影、客户端缓存与检索从原所有者的事实、推导和回执重建。新能力落入事实类型、命令、推导器（含槽位）或块，若需要另一类领域真相，按 PRD §11 保存反例并重审。[实现契约](../implementation-contract.md)

以下写集用于分派。各任务卡把职责落实到独占文件，共用声明和入口接线由集成者持有。公共类型的独立任务依据这些行为确定签名，保留现有工作树的目录和在途实现。

## 1. 来源引用与授权读取

- **入口与输入**。交入先收原件和回执。获准时，抽取将原题、本人原答、事后订正、教师批注和参考解答定位到各自的页区。材料打开、复盘跳转、同伴按需读取和推导 `gather` 共用内核读取语义。输入包含学习者作用域、对象、版次、锚点、读取模式、用途和请求范围。锚点由对象所有者定义，可指页区、块、字间位置、作答位、轨迹区间、消息片段或音频时间段。
- **返回与版本**。返回实际读取的版本、片段、范围、权限代次和可打开的引用，或者明确的等待、歧义、冲突或拒绝及可采取的动作。歧义定位原图，同一处待确认只询问一次。固定引用按权限读指定版，跟随引用要求当前版，截至范围保存因果水位和当次实际成员。已收集成员失效使候选拒绝，即使更正发生在水位之后。水位后新增成员按截至语义标记新鲜度。应有证据的槽位失效时，严格范围读取等待缺项。
- **更正与核权**。本人更正追加修订。抽取候选经采纳命令成为题或提交等有独立身份的事实，保留来源。已发题面固定，当前评估沿受影响的提交或证据引用重验。检索在用途范围内进行，命中后由所有者核准打开。推导 `gather` 封存实际输入，`derive` 消费固定输入。多步会话按需打开的片段留下读取见证，参与产物的实际依赖进入发布时核对的清单。实际外发、写入和接受分别核对当前授权，撤权后再授予也须用新代次重新读取。已在途的外发保留真实状态，迟到结果要重新核验。
- **观察反例**。对四页卷第 3 题，拍回识别为 D，学生从原图页区改为 B。迟到且读取旧修订的判分候选被拒，严格学情范围等到该题重判。早先已接受的判分及其依据能按权限回看。用撤权前的链接、缓存、摘要、搜索命中和恢复会话分别尝试打开或外发同一片段，均应阻断。
- **独占写集**。来源写手持有 `capture` 原件和定位声明、内核授权读取与清单接线。各域写手持有各自的片段和领域更正。关联单元 5、10、29、34。[内核规格 §5、§10、§16](../kernel-design.md) · [数据生命周期](../adr/0008-data-lifecycle-and-erasure.md)

## 2. 作品版本与宿主动作

- **入口与版本**。`content` 持有个人教材、生成作品和版本。学生及同伴在教材、题、课堂、试卷和会话打开同一份定义。版本化组件目录声明属性、组合、绑定、动作和无障碍语义。Agent 能组合原生组件、自绘带稳定对象的器材或坐标图、编写受控交互逻辑。逻辑消费宿主提供的输入与状态，返回结构化状态和已声明动作。宿主按作品、目录和逻辑版本运行，控制计算额度、网络及存储权限，并提供等价的无障碍操作。
- **动作与返回**。动作带作品版本、稳定对象和动作标识、活动或编辑的基版本、动作身份与正式载荷。服务端宿主核验状态、作者、权限和所要求的证据后，调用所有者命令，返回可继续的状态、可重开引用和回执。同一动作重试复用回执。探索可有即时反馈，存草稿可恢复，正式提交由学生动作触发。答案和解答图在符合冻结的揭示条件后才下发。备好、提供、打开、实际使用、受助完成和后续独立表现各有可观察的区别。只有实际展示才记帮助曝光。前题的帮助足以解后题时，正式证据记录其影响范围。
- **修订与接续**。教材支持嵌套页、稳定块、反引、标错和关联视图。视图打开原题和原作。本人作品的差异可分项接受、拒绝及撤销。获准的同伴可修订自己未被本人改过的草稿。并发编辑保留双方稿件，迟回执只确认对应编辑。SSE 重连重建已核验的作品版本与可见状态。失败时保留可读题面、已写草稿和继续入口。
- **观察正反例**。同一滴定图可在教材探索，另从正式题先交预测、再操作和揭示。用键盘和触屏操作同一阀门，提交读数及单位、被选对象、规定轨迹和解释。服务端拒绝绕过宿主的伪造轨迹。揭示前检查客户端载荷，确认答案仍在服务端。只拖滑块、存草稿或准备提示时，学习史仍无正式提交或实际曝光。把图修订进教材后，从旧课堂能重开原作品和当时所交。切断 SSE、碰撞两端编辑并重放迟回执，能找回对应版本和两份稿。
- **独占写集**。作品写手持有 `content` 的作品与教材声明、共享组件、宿主和渲染接线。发放、正式提交与曝光命令归 `activity`，会话持有历史引用。关联单元 18、31、32、38。[产品规格 D03、D04](../product-spec.md)

## 3. 冻结发放与全自动评估

- **发布与提交**。`content` 保存题面、共享材料、子题、作品版本、稳定作答位、提交结构和可执行规则。正式发放之前，核验界面可操作、作答可提交、评估器可执行，并用独立解法核对多解、边界、部分得分和反例。缺学校评分表时可核验一套注明来源的产品规则，学校分值保持未知。`activity` 发放固定逐题呈现、提交约束、评估规则、判定器版本、参数和汇总。在线、对话里的正式检查、课堂、纸卷回收和作品上传从正常入口提交，在同一事务登记评估意图。已获准的提交自动进入评估，学生交卷即可离开。
- **评估输入与结果**。逐项评估只读本次发放及契约允许的提交修订、原图、作品、轨迹和工具。学习者偏好和以往成绩用于其他教学任务。每项保留对应规则、方法与确切依据，分别给出结果、过程、约束满足情况和部分分。数值/单位、符号、图形或序列约束、模拟重放、受控代码执行及多模态 rubric 可组合。合法多解各按完整方案计算分数。开放题按冻结 rubric 自动交付有依据的逐项评估。有分值则按规则出分并汇总，无分值则交付约定的结构化结果。复盘可打开内核已接受的正式评估与依据。
- **身份与治理**。按发放题项、提交修订和约定规则识别评估，同次重传复用回执和已结算结果，真实再做保留新提交。补页与识别更正沿引用重评受影响项。自评另存，申诉发起独立自动复核并保留原判，规则换版用于新发放。原规则识别有误时，以可核记录复核并保留所用版本。争议题能停用具体用途、复验、更正或撤回，按影响重算当前结果。历史自核题补可验证的自动评估契约并保留原活动历史。

### 验收分母与完成条件

| 要回答的问题 | 验收口径 |
| --- | --- |
| **可判支持率** | 分母为全库已发、可发、应纳入的新录入及生成题的题版和评估契约组合，补充按作答结构、判定器组合及渠道盘点应支持的新题形。无契约、旧自核、缺评估器、因能力缺口留在草稿或停发的题在清单中占项。分子为经独立样例核验、能走发放→正式提交→自动得到生效评估的组合。目标为 100%，逐项展示缺口及原因。 |
| **实际自动完成率** | 每轮公布观察截止点和全部真实正式提交，按活动、提交身份和作答项去重，以当时最新提交修订的正式结果计。分母为正式提交回执所覆盖的作答项，包括范围内缺页、漏证、待判、故障、自核和人工路径。明确部分交卷时，范围外的已发题项单列为未交。分子仅纳入全套必判标准已由系统自动完成并生效的正式分或结构化评估。卷级完成还须全部必判项齐全且汇总生效。正常获准且材料齐备的正式提交应逐项达到 100% 自动完成。 |
| **判分真实性** | 在查看系统输出前，以独立解题、已知约束或评阅者按同版 rubric 建立对照。核对原答识别、规则版本、合法多解与部分分、过程、依据打开位置和汇总，并用成对反例观察输出变化。保留误判、错误定位、无依据结论及开放评阅分歧，按题形和规则版报告样本量、与对照的一致性及争议。记录实际判定器、模型与工具见证，复跑同版并测试更正和换版。真实性单独验收，即使自动结果已经生效也会记录错判。 |

逐项状态须可核对到原始回执和依据。有据的错误可以形成正式分。契约产出的「证据不足／未知」是可查的领域结果，和识别待确认、部分已评、待评、方法冲突、能力缺口、执行失败分别记明。任何必判项仍属这些灰色状态，或由人工判、自评、自核补齐，该作答项均不进入自动完成分子。显示阶段性结果和恢复入口，缺页及未交保留未知。独立人类对照用于测质量与复核证据。

- **观察正反例**。同一道断句题的两套完整合法断法各满分，拼接互斥断法至多按其中一套计部分分。滴定的正确终值配上违规或缺失轨迹时，过程项随真实证据变化。作文引证须打开其实际段落，受控代码评估须看到实际运行结果。制造中断和缺页，复盘显示各自状态。用两套冻结过程规则判同一步骤，核对分差来源，重开各自历史卷。
- **独占写集**。发放与评估写手持有 `content` 题版和规则声明、`activity` 发放、提交、曝光和评估槽位。作品渲染与效果账本通过各自公开契约接入。关联单元 8、23、27、29、39。[评估与题库设计](intelligent-question-database.md) · [产品规格 D01、D04、D09](../product-spec.md)

## 4. 证据图、记忆断言与教学使用

- **归属与入口**。`content` 持有学科图谱的节点、关系和教材/技能映射，`activity` 持有真实学习事件，`learner` 持有本人声明和学情槽，`companion` 持有可修订的记忆条目。「我」可打开判断、支持与反证，修改、拒绝或撤回记忆。「材料」可在知识点、教材、题、原作和错步间导航。同伴通过正常搜索、打开和备课路径读取同一证据。证据图及混合索引从这些记录和输入清单重建。
- **记录与输出**。连接原件片段、活动事件、声明或断言、教研决定及实物。断言保存作者、用途、适用范围、有效期、支持与反证及方法版本。注明原话、本人确认、同伴观察和推导的证据资格。发生时间、接收时间和因果水位各自保留。新判断记录实际证据和可改变它的后续观察。教法或选题理由能打开当时的原作及帮助。搜索命中、实际打开、模型实际收到的范围和成果的生效依赖各有见证。
- **教学使用**。同一份原作经转述或索引只算一份证据。表征、方法、条件、同题族解答曝光和实际帮助限定证据的适用性。先读有区分力的本人错法和成功方法，再决定直接迁移、用最小变化试探、进行教学或保留未知。题库先按用途、可发资格与硬约束筛选，打开真实题面和解法检查诊断价值，保留淘汰原因与供给缺口。更正、反证、到期和撤权重验受影响的当前判断与教研。合拆知识点或换教材沿带版本映射回看原作。`plan` 依据有效学情和目标、时间、作业机会重排未开始的活动，并保护锁定、进行中及已完成项。先留事前预测，再用可比的独立后测对账。缺后测显示待观察。
- **观察正反例**。固定同一个 45 和候选题集，分别让同伴读到曾独立列式和看例题后填答的原证据。前者转向新表征，后者自主选能区分两法的变式。只有 45 时方法未知。近似同名旧作、重复转述或单有先修边均不足以补证。更正原答或新增反证后，观察哪份未发短卷和哪条记忆重验。在已压缩或恢复的会话撤权，核对下一次实际请求及可发布结果。固定任务和权限，对照仅用近期上下文、混合检索和进一步沿图找原作与反证的表现，记录命中、错引、保持未知、实际换题、读入量、耗时和费用。
- **独占写集**。记忆写手持有 `companion` 记忆条目和召回、`learner` 声明与学情、`content` 学科图谱声明及证据图投影。会话执行、来源读取和 `plan` 目标/锁定由原所有者处理。关联单元 15、16、24、26、30、33、34。[产品规格 D02、D04、D05、D07](../product-spec.md)

## 5. Always-On 工作意图与结果发布

- **入口与所有者**。学生的消息、作答和设置经正常命令受理。启用后台教研后，同一 outbox 幂等启动或唤醒每位学习者一个稳定身份的协调流程。服务启动按当前设置补接。即使空待办，仍可在权限和额度内主动看旧作、过往讲义及计划，提出带依据、交付物、完成条件和预算的工作单。PostgreSQL 持有业务输入、工作意图、效果和回执，业务写与 outbox 同事务。Temporal 唯一恢复跨步执行、等待、并行和取消。Pi 按路线图承接单次采样及工具批次。
- **继续与回执**。已接纳的中途更正和已结算工具结果按顺序进入下一次采样。稳定工作与效果身份跨重试、重复入队、启动回执丢失和 Worker 重启。已确认结果复用，收费未知保留占额并核对。后台和主动请求各用其额度，子任务从父额度原子预留，未设额度时付费后台为零。已拒绝的意图随其生效条件保护，重复或已满足的需要可等待或复用现成成果。
- **发布与控制**。读取、实际外发、工具写入、结果接受按时点核对用途、代次、暂停及预算。备课完成须能打开获准的讲义差异、已验证变式或复习，且符合工作单交付条件。正文、回执和实物都可从 SSE 重连或历史恢复。只有写入回执且仍欠答复时显示部分交付。记录真实进度、发送范围、实际提供方和模型、费用或未知及下一步。临时原文按适用期限销毁。无模型时仍可打开已有材料和确定性活动。
- **观察正反例**。留获准旧讲义和两份有区分力的旧作，清空待办并关闭前台。真实后台自行读取、持久保存带锚点的块差异，在第一阶段落盘后、下一阶段开始前杀 Worker，重启自动续作。首次重开能查到早于重开时间的成果和回执。重复唤醒只认同一逻辑工作，已结算效果的实际调用只有一次，重试复用回执。让实际发送后的结果丢失，核对未知状态、占额及提供方记录。暂停、撤权和后台预算为零分别观察发送、候选接受与兜底。
- **独占写集**。执行写手持有内核工作与效果账本、relay、Temporal 执行器和 Pi 会话接线，领域成果经所有者入口交付。关联单元 12、14、17、35、38、40。[持久执行裁决](../adr/0007-temporal-durable-execution.md)

## 贯通旅程与成对验收

用同一学习库串联这些阶段。每段保存可由下一段打开的事实引用、回执和版本，同一素材在成对验收中只改变需要验证的条件。

| 学生实际走的路径 | 接到下一步的证据与反例 |
| --- | --- |
| **手机交入 → 材料/复盘 → 更正 → 打印回收。** 拍四页九题的真实校卷，含跨页材料和多个作答位。先收件，离开后从材料开练已核验题。缺页补拍，打开第 3 题原图并把 D 更正为 B。再从正常入口打印、手写、拍回同一冻结卷。 | 保留原件页区、活动与题项身份、自动判分、旧判拒绝及学情重验。检查成品可读性，核对文本层、附件和定位字段仅含许可的卷面信息。重复拍回保留一次提交，明确再做增加一次，缺页仍可补。改题库后按原活动打开对应发放。 |
| **复盘/同伴 → 教材 → 课堂/新卷 → 正式复盘。** 从校卷的读图步骤打开教材，让同伴生成骑行课。先预测、调停车段、按约束构图，换端从原进度完成陌生图。在同一学习库中请 Agent 生成自绘滴定器材、操作与评估，退出出题会话，用保存版从教材探索，再在新卷交预测、操作和解释。 | 在教材、课堂和试卷核对版本化对象、动作、已交轨迹及揭示时点。正确终值配一份不同轨迹，核对过程项与实际步骤。生成失败或操作中断时仍能继续作答。课堂根据答复仅调整未呈现部分，旧课堂支持回看原经历。更正、本人自评和申诉各有入口和回执。 |
| **复盘 → 证据图与「我」 → 同伴/「今天」。** 从错步回看旧作和帮助，用同一个 45 的两种历史复验选题。独立列式者用陌生表征。另一条历史由同伴自行发现最小辨别题，例如将 30 与 60 公里/小时等时的第二段改为两小时，使正确值 50 与直接平均 45 分开。改考试范围、作业机会或可用时间，再从「今天」开二十分钟练习或选择推迟、休息。 | 保留真实打开的两份原作、候选取舍和发放依据。留五分钟给切换与复盘时，约十四分钟的三题可入卷，额外的四分钟同类题舍去。只改变已有曝光时，检查独立迁移题选择是否相应变动。只交 50 时方法仍未知。保留锁定项和正在做的活动。先存预测再做独立后测，查支持、反证和误差。只有当堂受助时，后续效果保留待观察。教材映射换版后旧作仍可沿原身份打开。 |
| **关闭客户端 → 空队列主动教研 → 次日「今天」与教材。** 留前面旅程的旧讲义与两份获准作品，启用后清空待办。验收时无新请求、新材料或预排课堂。按 §5 中断 Worker。回来查同伴为何准备这份讲义差异或短卷，逐项采纳教材提议。 | 实际工作、打点、可打开的依据、正文、差异与已结算费用均对应离开时的执行。让原件更正或撤权与准入/结果提交竞争，核对旧候选拒绝、已发历史的固定身份以及未发内容重验。对照重复唤醒、暂停三周、未知收费、零预算和所有模型不可用的恢复路径。 |
| **换端离线 →「我」收回用途/导出/删除。** 手机离线写草稿、拍照或作答，联机后从平板重开原活动，查看同期编辑差异。用仅保存、仅本轮、不留存临时和学习使用分别交入。之后导出并以合成数据确认删除，恢复旧设备、旧 Worker 和旧备份。 | 离线待发与正式接受可区分，旧回执保留新稿。仅保存的链接无出站请求。口述确认后经同一入口使用，未选留存时无音频原件。仅本轮内容限当轮和本人历史查看，临时正文到期销毁。删除先阻断访问，再核验在线清除的 24 小时目标、设备、历史与默认最多 30 天的备份策略。无法证明防回退凭据完整时恢复保持隔离。用本人表达、引文和普通挫败核对 D10 正常入口、离线求助及主动外发边界。 |

跨学科用同样的正常入口和同一套版本、动作、评估及证据引用。每轮给真实 Agent 新材料，保存后另开活动。下面的对照和滴定、物理纸卷一起进入评估清单。

| 样本 | 要分辨的真实结果 |
| --- | --- |
| 古文断句 | 窗口宽度改变换行时仍提交同一版字间身份。两套合法整解分别满分，互斥拼接按整套计算。 |
| 音乐节奏 | 八格两声部各三次且仅在第 1 格同时响。两份不同的合规作品都满分，只多一处重合则只扣该约束。仅试听可回到草稿。 |
| 阅读与写作 | 开放评阅按冻结 rubric 引证确切段落，逐项给结果。引错段落进入质量错误，找不到必要依据按未完成口径记录。 |
