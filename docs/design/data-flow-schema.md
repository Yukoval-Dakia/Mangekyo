# 统一数据流转契约与图谱 Schema v1

2026-11-19。从正常产品入口打开一次活动，学生与获准的同伴都应能沿引用打开原题、原答、实际帮助、正式判分和材料出处。四层是数据的阅读顺序。事实、命令与提议、槽位与推导的写入沿用现有内核。图查询使用同一 PostgreSQL 数据，索引可重建。领域归属、端到端旅程和 100% 自动评估的三项验收指标沿用[产品共享合同](product-contracts.md)。

## 引用、访问与留存

| 引用 | 数据形状与规则 |
| --- | --- |
| 固定事实 | `{ id, rev }`。固定试卷题面、发放规则、历史提交、已发布作品及预测当时确实使用的来源。 |
| 跟随事实 | `{ id }`。跟随当前目标、教材、图谱节点及需要最新信息的来源。调用时由拥有者解析到实际修订。 |
| 读见证 | `{ id, rev, accessEpoch }` 加读取模式、用途和实际片段。工作区 basis 的 `epoch` 是兼容字段，在边界转换。内部内核引用保留 learner。 |
| 来源片段 | `fact + anchor`。先支持整对象的授权投影、原字段 UTF-16 半开区间、发放后的 `itemId + slotId` 及子路径。原图页区、教材块、操作轨迹、消息与音频有权威坐标后各自解析。评估 JSON Pointer 与来源路径段通过确定性转换，共用稳定作答位。 |
| 截至范围 | 保存当时的成员、输入位置和学习者 clock。有效成员后增只标 `behind`。已用成员失效则 `stale`，精确传递到下游。 |

用途为 `storage | assessment | teaching | research | analytics`。新事实默认 `['storage']`，显式新授权由命令写入。已保存的用途按当前兼容规则读取，遗留 `all` 不替代后来新增的后台启用、外发和预算授权。早期 SQL 与命令创建都须对齐默认。用途收窄、撤回与恢复推进 accessEpoch。固定引用也服从当前用途、历史修订用途、原始依赖和删除凭据。索引命中、授权打开、实际发送和产物依赖分别留下见证。读聚合与 Agent 工具从同一个已授权的投影取得数据。

留存取 `durable | turn_only | ephemeral`，与用途分开。本轮使用经宿主确认范围和接收方，可依许可用于当前回合。完成后本人可回看，同伴下一轮与长期图谱不再消费。临时原文按[数据生命周期](../adr/0008-data-lifecycle-and-erasure.md)清除，账本保存无正文的控制凭据。派生块、摘要、搜索片段、工作账本和外发请求都受原来源约束。重授后必须重新读和采样。

## 四层对象和现有分支映射

下表的 14 类是统一读契约中的对象形状。数据库已存的类型与名称先由拥有者适配。新写入口经领域命令单点收敛，旧 ID 和固定引用继续打开。产品现有的作品定义、记忆条目、效果账本等仍按各自契约持有。

| 层与统一对象 | 当前来源、收敛边界 |
| --- | --- |
| L0 `material.source` | `activity.textMaterial` 与 `activity.intakeDocument`。先用同一读入口查原件、状态、抽取与更正全文，保留两者可独立定位的修订及许可。4000 字字段只作预览。 |
| L0 `material.page` | `activity.organizerNote` 与 `workspaceEntry(page)`。新教材富块由 content 持有，块可嵌套、重排、反链和绑定题版及交互作品。并发保存带原版，按块接受提议，已有本人编辑受 sticky 保护。 |
| L1 `knowledge.concept` | `workspaceEntry(concept)`，补学科、别名、辨析及有依据的关系。 |
| L1 `knowledge.question` | 工作区题目及旧卷内嵌题。绑定作答契约、生成作品、评估契约、核验回执和来源。区分目标概念、先修、可选路径、最小条件改变和变式家族。 |
| L1 `knowledge.edge` | 旧 `workspaceEntry(relation)` 读为未定型关系。新关系由 content 的命令确认，机器推断先作为推导。 |
| L2 `activity.paper` | `workbookPaper`。先补可选固定来源题引用，保留旧卷足以读回的冻结内容，再收敛显示与发放边界。 |
| L2 `activity.submission` | 正式卷、骑行、课堂检查、RecallCard 与生成界面共用发放、题项、作答位和重传语义。过程与独立性来自实际活动记录。 |
| L2 `activity.exposure` | 帮助曝光分支的稳定展示、影响范围与内核刻度。仅提供、打开请求或送达载荷不构成展示。观测缺失保持未知。 |
| L2 `activity.turn` | `activity.studyTurn` 兼容读，记录用途、留存和当轮实际打开/发送的引用。历史作品挂载指向当时版本。 |
| L2 `activity.annotation` | 旧批注和观察。用已打开的原答 basis，保存作者与置信状态。转述、记忆摘要和原答同源时只计一次。 |
| L3 `learner.goal` | 现有 `activity.studyGoal` 经 plan 的目标入口汇入学习概览。 |
| L3 `learner.task` | 现有 `activity.organizerTask` 经 plan 保留手工任务、日期、锁定及目标引用。 |
| L3 `learner.preference` | 学习者明确声明的偏好由 learner 持有，独立于模型端点。companion 持有可更正的记忆，允许来源、支持、反证、适用范围、时间和拒绝。旧路由绑定备忘经原授权可读，扩大接收方须用户授权。 |
| L3 `learner.feedback` | 提议决策、评估申诉、用户编辑与 OCR 更正引用既有回执与事实。指标可由记录推导，避免重复存一份更正。 |

关系至少表达 `prereq_of`（前置到后续）、`part_of`（部分到整体）、`contrasts_with`（对称）、`targets_concept`、`variant_of`、`derived_from`、`explains`、`addresses_pitfall`、`supersedes`。每条确认关系有稳定 ID、端点、类型、方向、适用范围、来源见证及可选元数据。变式保存保留/改变条件、familyId 和有方向的 `spoilsNext`。看见旧题足以解该变式与看见该变式足以解旧题分别表达。端点和关系用途取交集。授权、检索和图遍历在读端逐项复核。

## 推导槽位与同一读入口

| 槽位语义 | 核心输入与产出 |
| --- | --- |
| `assess.grade` | 固定已发题、规则、判定器和实际提交修订。跟随 OCR/原答更正以触发新评估，保留原判。题库后来改标答只影响新发放。核证原规则识别有误时，经复核和新规则版另存评估，揭示原版与新评估。所有正式可判项交卷即登记。 |
| `knowledge.questionStats` | 按题版、家族、概念读取实际完成的评估及曝光，分桶统计独立与受助样本、实际耗时。样本不足保持未知。 |
| `learner.mastery` | 截至范围收集评估、帮助与已查证的批注。精确旧输入失效传播。追加新样本按新鲜度刷新。受助和独立作答分别计证据。 |
| `predict.forecast` | 事前固定输入、目标、截止条件、预测方法与水位。 |
| `predict.reconciliation` | 固定原预测、跟随获准的事后评估/更正与实际曝光。若目标作答已剧透标污染。结果进影子方法对照和后台复查。 |
| `plan.today` | 组合目标、任务、学情范围、近期错步、复习和待审提议。保留本人锁定。无模型仍能显示现成内容和确定性计划。 |
| `companion.reply` | 读取当前回合、获准偏好和相关事实，保存每步实际打开与外发见证。旧回复历史回看服从当前授权，续聊重投影。 |
| `research.agenda` | 由 Temporal 协调器在空待办也可唤醒。PG 检查用途、预算、拒绝与已有成果，按当前水位打开证据。通过已有提议和命令入口交付，复用已结算效果。 |

`open_learning` 以 `attempt | question | concept | material | learner_overview` 为入口。attempt 打开冻结题、原答、同期帮助、当前获准评估及批注，历史请求可打开当时评估。question 聚合题版、关系、实测统计和本人已见记录。concept 可打开两个方向 1 至 2 跳，返回获准教材、学情和候选题。material 按实际版本分页读取全文和反链。learner_overview 汇聚已授权目标、任务、记忆、学情、近期错步与「今天」。已有 `read_workspace` 走兼容适配，现有 SSE 与 GET 使用同一对象和挂载身份。

`search_learning` 接收 kinds、text、精确 tags、conceptId 与 hops（0、1 或 2）、edgeKinds、exposureFilter、masteryFilter、onlyUnverified 与有界游标。游标绑定学习者、用途、查询及读取水位。没有曝光记录与可靠未曝光分别表示。先由 PostgreSQL 当前版、标签或结构索引找候选，再由领域所有者和内核核权，返回可打开引用。边、标题、片段和计数都受相同约束。实施初期按未撤回事实的学习者/类型索引、fact_revs JSONB 包含索引、关系 from/to 投影索引、曝光 question/family 索引和槽位 scope 索引验证实际查询计划。A/B 内核反查对照沿用[内核规格](../kernel-design.md#13-两种实现的共同比较协议)。

## 接线与正常入口验收

| 断点 | Wave A 独占接线 | 通过证据 |
| --- | --- | --- |
| A1 默认用途 | 内核 schema 新安装与版本化迁移、缺省 create 的 normalizer。 | 新插入与新命令只有 storage，显示仍可读，教学和新后台未授权不可读，升级后旧数据和显式许可可正常访问。 |
| A2 命令传播 | 单元 4 的闭包、Studio 统一 hook 注入。覆盖 library、practice、organizer、workbook、memory、intake、workspace-access、workspace-agent 和 sessions。WIP 的额外授权、回合登记与业务回执在同一事务继续执行。 | 从正常命令更正/收窄权限，跨域候选失效，等待唤醒和 outbox 同事务，旧 Worker 拒绝。断言事务尾部错误整体回滚。 |
| A3 目标、任务与今天 | 复合概览先接按条可授权的目标与任务，计划保留至 Wave B 汇入复习、学情与待审。 | 同伴确实发出获准目标/任务片段。未授权项、撤权和实际 outbox 作用域分别检查。开启无模型仍可按本人约束继续。 |
| A4 作答与 rubric | 共用作答复合投影，复用旧卷当前评估读路径，关联准确的尝试与题项、来源及 manifest。 | 卷面和同伴在同一次作答看到同一已接受分和评语。更正、撤权、相同卷两次作答与历史手动判分别核对。 |
| A5 交入全文 | 来源读分支把已有全文读取改为按调用用途及实际修订返回，复用学生活动和同伴读法。 | 原 PDF 更正后打开 4000 字以后指定段落；保留原始/修订锚点。仅本人可读的纠错稿不回退成给模型发送旧预览。 |
| A6 组卷题目血缘 | 从工作区和 StudyKit 跳组卷时传固定来源题引用。保存命令重读指定版并坚持来源用途，规范化为冻结题项。旧卷兼容。 | 从两处正常入口开新卷，刷新仍连回题库原版；更新题库后历史卷不变。撤权后旧草稿不能凭复制文本发布。 |
| A7 RecallCard 作答和曝光 | 同伴/试卷共享活动命令，提交有可辨识题项；只有获准展示回执才能登记曝光。已有帮助曝光领域命令供两端复用。 | 相同正答的独立、先见参考、未知三例。刷页、重传、再做、揭示前网络请求与查看后一题分别核对。 |
| A8 备忘与检索 | 保持旧备忘历史，新增本人可管理的偏好与记忆，接类型化检索和可信来源。 | 切模型后同意的偏好可加载，旧端点授权不会扩大。两份同名旧作、反证和撤权后实际请求验证。 |

Wave B 在兼容读背后收敛新写的教材、题、语义边、提交和曝光，接通正式评估槽位、学情、今日计划与图查询。先以实际版次、精确引用、可纠正的历史证明每条替换。使用对照验证 `behind` 与 `stale`，索引从事实和推导重建，读写仍经过原有入口。Wave C 接预测、对账、真实题型统计和反馈，恢复空队列教研。以同一学习库跑四页拍卷更正、教材/卷/同伴共用滴定或断句、同分不同帮助、事前预测和真实后台中断，再逐项核对自动判分、旧规则保护与撤权。

现阶段分支可用结果和待集成证据见[产品共享合同](product-contracts.md#比较与交付证据)。本契约约束整合时的读写路径与验收，既有代码仍逐步接线。
