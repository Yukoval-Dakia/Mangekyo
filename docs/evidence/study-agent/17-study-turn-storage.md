## 点击至文字实际绘制

Chrome Element Timing 的 `renderTime` 减去点击事件时间。每次等待对应文字元素的独立标识，超时记缺样。最终样本来自同一会话逐次操作。

| 最终轮操作 | 小于 150 ms / 发起 | 范围 |
| --- | ---: | ---: |
| 打开已读片段 | 6/6 | 33.5–67.5 ms |
| 预览原话 | 6/6 | 32.5–37.8 ms |
| 确认写入 | 1/1 | 34.6 ms |
| 撤回写入 | 1/1 | 33.5 ms |

首轮 13/14 有实际绘制时间且均小于 150 ms，撤回成功但未收到文字绘制条目。首轮重复确认返回 409；后续修复从事务内命令记录恢复同一次确认的回执。两轮合计 27/28 有低于阈值的实测。撤权对照核对了内容与写入结果，没有计入时延分母。[逐次绘制、回执、拒绝回包及 PG 页版本](17-study-turn-storage.json)
