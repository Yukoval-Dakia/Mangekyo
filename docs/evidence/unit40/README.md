## 第一组真实教学记录

原题是以 30、60 公里/小时各骑一小时。两位测试学习者都答「45 公里/小时」。Agent 在两个相同的目录中分别选择读取「分段行程练习」；它没有打开「速度单位换算练习」。只有它请求读取后，相应旧作正文才进入模型上下文。

| 案例 | Agent 实际读到的区别 | 第一步 | 收到自由作答后 |
| --- | --- | --- | --- |
| 独立完成旧作 | 学生在看到反馈之前写出两段路程 48 和 36 公里，以及 84 ÷ 3 = 28。 | 跳过基础辨析，给出 12 公里/小时骑 1 小时、24 公里/小时骑 2 小时的迁移题。 | 测试者写出 60 ÷ 3 = 20，Agent 接着给两段路程相等、速度不同的任务。 |
| 看过完整例题 | 旧作里同样有 84 ÷ 3 = 28，完整列式来自先展示的解答，学生只填了 28。 | Agent 将第二段延长至两小时，问此时的平均速度。简单平均与按总路程、总时间计算给出不同的数。 | 测试者写「我把两个速度加起来再除以二」，Agent 转为讲解这一步，让学生分别计算两段路程，再检查总时间。 |

两次追答均从实际浏览器提交。页面显示提供方返回的模型标识。诊断的公开理由由模型选取原因、系统组织措辞，其余教学动作直接显示模型给出的公开理由。服务商所报路由、实际取回和引用的旧作、逐轮原文均可核对。底层权重版本与逐次账单无法从此网关验证。[逐轮记录](teaching.json)

在修订后的提示下，另一条模型路由也在独立旧作后布置了反向求速度的迁移题，在示范旧作后只改变一段时长来追问。前者收到正确解答后，改问两段路程相等、速度不同的情形。后者的一次追答遇到未知外部效果，记录保留其状态。[本次复验](release-teaching.json) · [桌面实拍](desktop.png) · [手机宽度实拍](mobile.png)

可以直接打开两份可继续作答的会话。第一份里，学习者已经完成反向求速度的任务。第二份里，Agent 先问「多出来的一小时改变了哪个量」，收到「多用时间，总路程还是不变」之后，请学习者比较以 30 公里/小时骑一小时和两小时分别走多远。页面逐轮保留了这次调整的依据。[独立作答会话](http://127.0.0.1:4317/?session=0A67D546514563364D34F2C5FF) · [例题后填答会话](http://127.0.0.1:4317/?session=83B15641D779B3CE4D5815436C) · [第二份的三轮原文](assisted-followup.json)

## 运行中的偏差

在一轮复测中，模型已经读到了独立草稿，却仍然提出基础辨析。我们保留了这一对结果，移除了提示中偏向诊断题的单一范例，并明确让模型比对旧作中已经独立展示的具体步骤。[复测原始结果](first-recheck.json)

自定义模型测试使用同一个兼容网关，切换到另一条模型路由。面对「停车时间算不算」，它曾原样重复上一道题。修订后，系统会拒绝原样重复的诊断题并允许一次纠正。测试者再次说明码表的计时差异，模型选择了澄清，询问「车轮在动的时间」和「从出发到抵达的总时间」各指什么。这条记录保留了前后两种表现。[自定义模型的完整对话](custom-provider.json)

另有网关请求结束时无法确定模型是否执行。应用停止这一轮的自动调用，显示可核对的请求标识。两条额外会话的状态和已完成教学轮次原样保留。这里能验证失败如何呈现，不能据此判断网关是否收费。[未知结果回执](provider-unknown.json)

## 中断与恢复

- 接收进程在两个 HTTP 回执返回后被强制结束。当时后台处理尚未启动。重启后，数据库中登记的两份作答均在原会话生成结果，四次成功教学各有一个已交接的执行标识。后续一次不确定的外部效果被阻断。[回执与原始会话](teaching.json) · [数据库账本](ledger.json)
- 真实 Temporal 测试杀掉处理旧任务的 Worker，再启动新版。新任务由新版完成；旧任务等待匹配版本，恢复后沿用原 Run ID。测试还覆盖执行中及结束后丢失启动回执、重复交接及最终失败回写。[Temporal 运行记录](recovery.json) · [复现实验](../../../executors/temporal/README.md)
- 真实 PostgreSQL 测试覆盖迁移失败整体回滚、并发迁移、旧等待记录、取消、迟到结果、重复效果和授权失效。v4 起，队列身份保存在数据库中。只运行 Worker 的进程可连接兼容下限允许的新 schema。首次从 v4 以前的原型升级，应先排空旧队列。
- Chrome 验证了证据展开、自由作答、刷新与手机宽度。设置面板可以修复损坏的配置，保存、移除或更换密钥。切换端点会清除已存旧密钥及尚未提交的密钥输入。密钥不返回浏览器。
