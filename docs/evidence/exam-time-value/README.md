# 整卷反馈用时条

本轮以 `1aceb2eb7b123ea34172d99fa3e5679f70a8ebe7` 为基线。Google Chrome 157.0.8103.52 打开本机构建的 Web。隔离宿主使用内存 PGlite、内核 schema、Studio HTTP 与 Workbook 模块，全程未启动付费服务。

## 普通交卷

[browser.json](browser.json) 记录三道数值题的真实交卷回执、页面请求、DOM 色块宽度与焦点。整卷 2113 毫秒，第 1 至 3 题分别为 375、664、996 毫秒，剩余 78 毫秒单列。真实详情没有分类字段，页面显示逐题节奏未知。[390 像素视口](mobile.png)

键盘 Enter 从第二段聚焦第 2 题。手机宽度下展开逐题占比，点击第 3 题后焦点进入相应反馈。额外两次提交通过普通 HTTP 入口写入零耗时和稀疏计时，两者都收起比例条。将同次作答的伴学权限从开放改为撤回后，修订从 2 变为 3。点击仍挂载的旧段触发重新读取，旧版条及其题号入口随即消失。随后在隔离数据库中撤去这次作答的 storage 用途。再次点击已打开的段时，真实详情响应已排除该作答，旧条收起。这一步用数据库构造授权变化，页面和 HTTP 均走正常入口。

## 四态消费契约

[contract.json](contract.json) 和[触屏截图](contract-mobile.png) 来自独立回放。五题卷和提交走真实 HTTP，仅给详情响应补入可选的 `examTimeValue`。回放采用域 3 的 `plan/exam-pacing@2` 合成证据经实际 Python worker 得到的结果，并绑定本次验收的提交及冻结卷修订。四种标签、单题未知与摘要均来自该结果。Chrome 触屏点击超估时段后聚焦第 3 题。错卷版、错作答、题号对调或显式 unknown 都收起比例条。

域 3 计算提交为 `2afd9a32d12478a06c0ea2a08b4ad83ae6cdcb90`。计算结果的 `total_duration_ms` 是各题合计，占比的分母取归档整卷有效用时。待域 1 的正式读口在当前用途及收件人下重开操作证据、正式评分与冻结题版，并约定携带纸版引用的响应字段；真实产品正例须在该宿主交付后复验。
