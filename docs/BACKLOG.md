# Mangekyo 工作单元

按依赖排序。每个单元注明：产出、依赖、验收。做单元前先读 `docs/kernel-design.md` 与 `docs/PRD.md`，术语以 `GLOSSARY.md` 为准。标注 **[契约]** 的单元定义全局类型，值得更强的判断与单独审查；其余为填充层，便宜模型按样例独立完成。

## 第一批：内核本体

1. **[契约] workspace 与 Db 接口。** pnpm workspace；`Db` 接口 + `pg` 实现 + `@electric-sql/pglite` 实现；`learners` 行锁与刻度助手。验收：两个实现在同一套用例下跑过。
2. **[契约] schema 与 define API。** §2 全部建表 SQL（幂等迁移 runner）；§3 五个 define 函数与 `ctx`/`tools` 类型；模块加载器（目录约定）。验收：一个手写的空模块能加载。
3. **命令执行。** §4 全路径含幂等拒绝、触发器、传播调用、receipt。验收：不变量 4、10。
4. **生效与传播。** §5 accept 全路径、§6 传播循环、§7 work 表与 worker loop（in-process）。验收：不变量 1、2、3、6、7。
5. **采纳、提议、撤销、用途边界、效果账本。** §8、§9、`ctx.read` 的 purpose 检查。验收：不变量 5、8、9、10。
6. **Python worker。** §11 子进程宿主 + `python/mangekyo_derive/` 约定 + 一个确定性的记忆强度推导器（比如简化的 FSRS 变体，纯计算）。验收：TS 调 Python derive 跑通样例。
7. **生成器与检查。** `scripts/new-deriver`、`new-module`、`check-structure`。验收：生成骨架直接编译通过；人为制造一个越界 import 被拦下。

## 第二批：让「拍卷子→今天」竖切能跑

8. **[契约] capture/content/activity 的事实与槽位类型。** 原件、题目（大题/小题/叶题、任意 metadata）、提交、抽取/解答/判分槽位。题目结构参考旧 `CONTEXT.md` 的 StructuredQuestion 术语，**不复制旧 schema**。验收：类型评审一次通过；样例数据能表述旧测试集的四页卷子。
9. **确定性填充层：** 一个占位抽取推导器（读图片占位输入→产出固定结构的题与作答，供管线联调）、解答/判分的确定性版（对选择题做精确匹配）、掌握度的 range+Python 推导器、今日视图的惰性推导器、计划兜底推导器。
10. **采纳接线。** 抽取槽位 adopt → 题目与提交事实；学习者更正命令（sticky）。验收：不变量 5 + PRD §2.1、§2.2 脚本化走一遍。
11. **CLI/HTTP 薄入口。** 从定义目录自动生成：`POST /commands/:type`、`GET /slots/:type/:key`、`GET /slots`；无手写路由表。验收：curl 走通 §2.1 全流程。

## 第三批：智能与会话

12. **[契约] 会话宿主。** `sessions` 表（工作单字段 + 逐步追加的 step 日志 + 恢复时从最后一步继续）；agent SDK 选型（先核对候选现状，偏好 TypeScript、provider 可配、能把工具声明喂给循环）；工具 = 命令与槽位读取的自动投影。验收：一个三步会话被 kill 后从新进程恢复并完成。
13. **同伴 v1。** 会话定义 + 提示词 + 读视图/发命令工具集；destructive 命令走提议。验收：PRD §2.4 对话可跑（可用最便宜的可用模型验证）。
14. **教研会话与需求驱动。** 工作单：备好「今天」；触发：关键槽位 stale/behind 且学习者不在场；交付校验。验收：§2.3 可跑；无新事实时不产生任何运行。
15. **对账。** 预测槽位 + 对账推导器 + 「我」页所需视图。验收：§2.5 末段可观察到。

## 第四批：横向

16. **重放（shadow）管线。** 对一组既有槽位跑指定推导器，产 shadow 推导 + 对比报告。验收：§2.10 一次完整走通。
17. **效果账本的模型网关。** deriver tools 里的 `callModel(taskTier, prompt)`，经 effects 表 + provider 配置 + 花费记录。
18. **多设备最小集。** 命令带 id 的上行队列约定 + 视图快照下发。验收：§2.8 用两个浏览器走通。
19. **界面骨架。** surfaces/web：今天/材料/我/交入，消费 §11 的入口，无业务判断。
20. **危机转介不变量。** 由 owner 指明范围后单列；在此之前不假设实现。

规则：单元 8、12 开工前各做一次独立设计评审（一份一页的批评文档，对照 kernel-design 与 PRD §11 的推翻条件）。单元间冲突时，类型表先冻结再开填充层。
