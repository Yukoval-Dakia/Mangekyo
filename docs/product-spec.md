# Mangekyō 产品规格

2026-11-18｜现行。Mangekyō 为一位学习者长期工作。学生可以带着一道题、一张卷子、一个困惑或一段空闲时间进来，带着一份能用的讲解、练习或安排离开。下次回来时，系统能接上原来的学习，并从上一次真实发生的事里改进判断。

本文件将[产品概览](product-overview.md)写成可交付、可验收的行为，承接 [PRD §3](PRD.md#3-从场景得出的产品承诺) 和已裁决的 D01–D10、F01–F73。概览里的保持曲线、诊断题搜索和课表比较是候选方法。交付按学生能完成的行为、系统能提供的证据和遇到失败时的实际表现判断。功能范围与当前实施状态见[功能去向](feature-disposition.md)。

## 1. 产品范围

| 能力 | 要交付的完整功能 |
| --- | --- |
| 材料与作品 | 多页交入、复杂题面、来源、更正、语义检索、纸上闭环、按页面组织的个人教材与题目双向关联 |
| 学习活动与评估 | 单题、整卷、按次编排并用后归档的课堂、阅读检查、解释、作文、代码项目；草稿、提交、自评、正式评估与申诉 |
| 理解学习者 | 有条件的能力与记忆、具体误解、本人成功方法、过程习惯、当下声明、教学效果及证据 |
| 教学 | 分阶提示、渐隐例题、自我解释、辨析与交错、教同伴、轻量检查和之后的独立检验 |
| 目标与安排 | 目标生命周期、学校进度、预习、考试、时间约束、进行中保护、长假回归及稳定安排 |
| 教研与供给 | 找出缺口、检索或生成材料、并行求解验证、提前交付、方法重放与替换、可停止的复杂后台工作 |
| 同伴 | 唯一对话者、多轮工具、计算工作区、长期可纠正记忆、绘图与按需语音；通过统一命令行动 |
| 自主权与可用性 | 多设备、短暂离线、完整数据控制、真实费用与模型设置、少打扰、失败恢复、危机支持与转介 |

### 学生从哪里开始

| 入口 | 学生能做成的事 |
| --- | --- |
| 今天 | 看见已经备好的课堂、试卷或复习，知道为什么现在做、预计多久、哪件可推迟。从原进度继续，也可以换成练习、翻材料或今晚休息。 |
| 材料 | 找题、浏览知识点和个人教材、回到交入原件。从一道题直接开练，或从知识点、笔记和原卷开始组卷、上课。沿引用查看原题、自己的旧作答和当时的帮助。 |
| 同伴 | 从题目、讲义、教材或自由对话提问。只要带着来源进入，同伴就指向正在用的那个版本、步骤和获准读取的已保存草稿。能问「为什么这样教」，也能请它找题、准备图或提出调整。 |
| 我 | 管理目标、学校进度、时间、数据用途和同伴记忆。按知识或任务查看系统说自己会什么、现在还能不能做出来、凭什么判断以及哪条记录可以更正。 |

四处都可拍照、交文件、交文字或按需口述。题目、笔记、活动和历史会话可直接打开指定对象。刷新、换设备或短暂离线后从已保存进度恢复。离线时可读已保存材料并草拟或提交待发作答，联机后同步、处理并给出正式结果。首次使用可以从一句问题开始，无材料、无模型时的学习路径见 D08。

## D01 纸上学习与稳定身份：纳入

- 一次交入可以包含一本资料的部分页、多张卷面照片或一段原话。持久交入先给可回看的回执和原件。获准用于学习的材料才进入持续抽取、题库和学情处理。仅保存的原件由本人打开，等本人改变用途。仅本轮使用和不留存临时按 D06 限于当次获准处理。学生可以离开，回来能看到可使用、处理中及需要本人确认的部分。
- 抽取分别保留题面、本人原始作答、事后订正、教师批注、参考解答及其来源页区。含糊的一处只询问一次，能打开局部原图、选择候选或直接填写。本人更正生成新修订，识别重跑不得覆盖。无标准答案时按 D02 独立求解并核对，按 D04 评估。
- 内容版本、活动实例、每次真实提交各有身份。活动冻结实际发出的题面、选项、共享材料及任务要求；题库后续更新不改历史题面。
- 从安排或材料生成可打印卷，长材料完整跨页、文字可读；保留共享材料到小题的关系，不能靠裁切或不可读缩小通过验收。
- 打印件附不含答案的活动/题目定位信息。拍回后匹配原活动与题目；重传同一交入不造新提交，明确再次作答则保留新提交。匹配不确定时让学习者选原任务，不能猜测合并。
- 同内容重印复用原发放身份，冻结内容变化产生新发放。部分回收合法，缺页/未交保持未知而非零分；补页只补对应提交，打印/预览本身不产生掌握证据。
- 刚交入的已可用题可直接开练，不等全部抽取、判分或翌日规划完成；正在做的活动不被后台重组。
- 落点：content 的内容版本；activity 的冻结任务、提交；capture 的原件与定位。命令负责打印活动创建、交入匹配和更正，块负责打印与作答呈现。
- 验收：同卷打印→手写→拍回→再次上传，只得到对应的一次提交；明确再做一次得到第二次。长阅读跨两页不丢文；改题库不改变已发卷面；模糊定位进入待确认而非重复收题。清洁练习打印成品的文本层、附件和定位字段不携带系统答案/解答，答案版须明确另行生成。

## D02 题库、知识图谱与个人理解

### 题库与智能匹配

- 题库里的题可独立打开、搜索、更正、复用。每个版本保留来源、共享材料、子题、作答位及各自要求，保留公式、图和选项与对应关系。可供教研使用的版本还要关联已核对的解法、关键步骤和适用条件。已知能区分的错法、目标技能、表征和难度可追溯，缺少依据时标未知。接触了哪版、作过几次、看到哪级帮助属于实际学习活动。
- 学生或同伴能按目的提出找题请求，例如「练两段速度，和上题相比只改一个条件，我没见过解法，直接平均会答错」。匹配先筛用途、可发放性和请求的硬约束，再评估方法、适用条件、干扰错法、表征、难度、接触史与时间是否适合。最后读实际题面、解法和引用来决定。能说明所选题练哪一步、为何适合当前目的、哪些条件仍未确认。
- 本人的获准材料和已验证题优先。有缺口时才按授权外找或生成，给出匹配不足或采用替代题源的理由。可接受不同有效解法。生成题由独立解题者各自完成，核对答案、单位、隐含条件与可接受解法，适用时用计算或模拟验证。答案冲突、条件不足或题面有误的题可查原因、修订、重算、停发或撤回。供给不足时可交付符合约束的较短卷、请学生同意放宽某个条件，或明确还没有题可用。
- 诊断题应能让当前有证据支持的不同解释产生可区分的结果。先看获准的旧作，足以决定下一步时直接教学。若两种解法在换了数字的题里仍然同答，可选择只改一段时长且能区分解法的变式。若几种回答会导向相同教学，可省下追问。意外回答保留原话并允许新解释。

### 知识图谱与学情

- 学生可从教材章节、考点、知识点和题目相互导航。在知识点展开先修与后继、方法、适用条件、相关题和个人教材，也能沿选中的证据到原作。子技能拆到不同表现会改变教学帮助、且能实际观察的粒度。证据太粗时保持粗粒度。图谱关系组织学科内容，学习记录独立支撑个人判断。
- 能力判断的粒度是知识/子技能，以及有证据支持的表征、方法和情境；记忆状态单独表达。不能从做过某一题推断整章或所有情境都掌握。
- 保留具体误解与本人成功方法的候选解释、支持/反对证据和方法版本。改善、复发、退役由新证据改变当前推导，历史解释仍可追溯；不采用固定“连续几次即会”的通用阈值。
- Backtrace 同时找本人以前的相似错法和成功解法，允许跨章节；每项打开原题、原提交和当时帮助。推断与本人原话分别标明，检索无结果如实返回。
- 内容和个人经历统一按意义检索，覆盖题目、笔记、本人解释与聊天；按具体方法、适用条件、先修和易错机理组织检索任务。先过滤用途再检索，摘要、向量和重排也不得越权。
- 知识关联、先修、教材章节映射是内容事实；关系不自动赋予掌握证据。合并保留旧 ID 的重定向与原学习史，拆分/教材换版保留映射修订，不能按章节重建清空学情。
- 成长叙事和同题比较必须引用真实证据，分开独立性、错步、用时和条件变化；本人可纠正事实或质疑解释。
- 「我」分别回答学生在哪些条件下曾独立做到、隔一段时间后能否在可比的陌生任务中做到、当前困难有哪些解释。每项显示适用范围、支持和反证、题目的新颖度、实际帮助、方法和时间，以及下次哪种可观察表现会改变判断。保持估计随读取时刻和新证据更新，过去成功的经历仍可回看。没有独立成功证据时优先了解能否做到。题目额外增加难点、重学或帮助曝光会限制其作为间隔保持证据的资格。
- 落点：content 拥有知识/方法/映射事实；learner 声明和 activity 经历作为输入，诊断、Backtrace、叙事是推导。索引是可重建执行产物，不是第二份事实。
- 验收：找回跨章节的本人错法与成功经历；新增未答题且证据/标定未变，旧掌握判断不漂移；换教材后原作答仍可查；误解被反证后不继续按旧标签选题。

## D03 活材料、图与草稿：纳入

- 笔记主要由 AI 依据学习者的学习经历、目标与已有理解整理和编写，供学习者继续学习；讲解、例题、图示与学习检查可以共同构成内容。学习者批注、纠正和编辑的能力继续保留。
- 知识库是以 Notion-like 页面组织、由 AI 持续维护的个性化个人教材。页面大小由内容决定，一个细节也可独立成页。针对具体问题的讲解出现在题目下或对话教学中；题目关联知识点及相关笔记，笔记反向关联题目，双方均可实际打开。
- 笔记采用稳定块身份和有基版本的修订，支持公式、图、可交互内容、引用、反向引用和块级标错。长短组织是内容视图，不能丢失完整作品。
- AI 修改已有作品先形成可查看的差异提议；学习者可接受部分、拒绝、撤销。本人修改不被后台再生成覆盖。新的独立草稿可自动准备，但不冒充已改好的本人作品。
- 新独立内容的准备先是 content 草稿槽位中的推导，有稳定推导身份；成为可独立编辑/保存的材料时，经 content 采纳命令创建新的内容事实并保留来源。非破坏性新建按既有采纳规则执行；合入或替换本人作品必须提议确认。它不同于 activity 的作答草稿，不建立无所有者草稿库。
- 活动草稿和作品编辑保存明确基版本与客户端编辑序号。旧保存回执只能确认对应编辑，不得清空更新草稿；冲突保留两份并给出合并/选择入口，不能按设备时间最后写入获胜。
- 题目、笔记、同伴三个表面都支持带版本的图与交互块，交互事件可送回同伴。题图不预先泄露解答；解答图只在相应帮助动作后出现。
- 历史聊天绑定当时作品版本，重开可复用已完成图与帮助；更新笔记产生新版本，不追改历史消息。活动刷新、深链、新窗口均恢复同一活动，另开练习必须显式创建新实例。
- 落点：content 拥有作品块及修订；activity 拥有作答草稿；companion 拥有历史引用。继续使用事实/命令/推导器/块，编辑协议由内核公共能力承担，不引入真人协同或通用协作平台。
- 验收：旧回执迟到仍保留新稿；两设备冲突两份皆在；AI 改首块失败不会吞后续提议；重开旧聊天显示旧图，编辑新笔记不改变过去展示。

### Generative UI

- Agent 能依据当前内容和教学目的在题目、教材页、课堂和对话中选择、生成并组合产品支持的交互块。交付的是学生可操作的内容，例如可调停车时长的图、对照两份解法的视图、先记录预测再揭示结果的检查题。图形规范和交互方式由产品统一，Agent 按任务生成变量、图形内容、检查条件与步骤。生成结果使用带版本、可校验的块和动作，绑定实际题目或作品版本。块可以由计算产物驱动。动作走现有命令和读取边界。
- 学生操作后即时看到与条件一致的反馈。在探索时可以反复调整。学生选择把当前状态交给同伴或提交检查时，带上所选状态、当前版本和获准的回答，同伴据此调整讲解。操作、草稿、正式检查题提交及观看帮助各按实际行为记录。独立检查先收答案再揭示反馈。答案及解答图在相应动作前不得随作答块交给客户端。
- 学生可以继续同一活动、把有价值的图和解释整理成教材草稿，也能在历史里复现当时的图、已保存状态和结果。生成失败或块暂不可用时，保留可读题面、已写作答和明确的恢复入口。等价的键盘、触屏或表单操作能走完同一个学习步骤。
- 验收时用一组新的骑行条件请求图与预测检查。学生操作后同伴能引用本次操作，检查结果进入对应活动。从题、教材和对话都能打开并操作版本化块。修改教材后仍能回到旧会话看到当时的图和结果。

<a id="d04"></a>
## D04 课堂、试卷、评估与教学效果

### 学习型课堂

- 每堂课围绕学生想弄懂或能做出来的一件事独立编排。由题目和讲解组成讲义，开始前准备第一步、必要材料和可执行的后续分支。学生可以从「今天」直接上课，也可以带着正在做的题、教材页或自由提问请同伴开课。
- 课堂可以先请学生解释或做出预测，再用图或操作验证，让学生构造反例，最后检验能否在陌生条件下独立使用。已经会的步骤可以跳过。卡住时只给所需的帮助。达到目的可以提前结束。课堂保留实际使用的编排版本、内容引用、作答与帮助，调整仅影响尚未呈现的部分。中断后继续同一次课堂，结束时可回看、另开新课或把可复用的解释整理进教材。
- 具名教学方法包含分阶提示、完整例题到留空再到独立作答、自我解释、无标签方法辨析、交错练习和先试再讲。不给辨析题的标题预先标出应选方法；查看完整答案是明确动作。
- 复用已生成提示并从上一阶继续，显示后才记帮助曝光。聊天中实际出的检查题建立正式活动，回答成为提交，不能只留下无法对账的对话文字。

### 练习型试卷

- 学生可做学校原卷、选现成单题即练，也可从知识点、个人教材或同伴发起组卷。用一句话即可指定范围、目的和时间。可以调整系统理解的范围与约束。组好的试卷可在线做或打印拍回，均按 D01 保持身份。开卷前能看到目的、预计时长、覆盖范围、使用方式及可能的缺口。需要独立辨析的方法和答案留到交卷或主动求助之后。
- 组卷先用 D02 筛到真实可用的题，再比较整组能提供的练习机会、冗余和用时。巩固可以有意重做原题，再换条件。要检验独立迁移，选用未做过、没见过该题解答或足以直接还原答案的等同示范的任务。题名、前题和附带材料都给学生留出自己选择方法的机会。找不到这样的题时，可以先做巩固，并标出迁移待检查。选题覆盖必要的关键步骤、情境或重复次数。把读题、切换和复盘计入时间预算。用时证据少时给暂估范围并留出余量，时间不足时减少题量并指出暂未覆盖的部分。
- 开卷后固定题面、顺序、共享材料、作答位及评估要求。可以跳题、回看、暂停、暂存、换端、明确交出已做部分。默认交卷后看逐题反馈。学生主动求助时保留原活动和草稿，记录实际展示的帮助与受影响的作答内容。前题的提示若也教到了后题要独立完成的办法，复盘须标明。
- 整卷复盘能区分完成情况、答案结果、关键步骤、可用证据及受助范围，每一项能跳回原题、原作答或原图。学生从错步可更正识别、提出申诉、打开对应教材或安排一堂课。想确认会了可以选择原卷重做或另开变式。每次真实作答单独保存，新一轮不会替代过去。

### 同一评估契约

- 所有活动评估都回答同一组问题。学生收到的是哪版任务、实际交了什么、当时约定怎样算完成、哪一步有证据、哪些仍未知、学生接下来可以采取什么行动。规则随活动冻结并可追溯，包含适用的结果要求、关键步骤、允许的等价解法和部分得分条件。正式结果指向任务、提交修订、规则和方法版本，并定位到作答位、原图或作品片段。
- 评估规则可以来自获准读取的原卷或教师要求、学生声明，或备题 Agent 随题设计。Agent 能指定可交的答案或附件、要观察的证据、部分得分或反馈，以及每项的核验方法。发布前用独立解法和有已知结果的样例核对，覆盖有效替代解法、部分完成和依据不足。学生能查看规则来源与计分方式，并可更正识别或在发放前确认争议要求。学校规则缺失时，显示系统反馈的依据，学校分值保持未知。同题型的不同任务可以采用不同规则，新订要求适用于下一次发放。原卷规则识别有误时，以可核对的原始来源复核，保留当时记录和历次结果。
- 选择和数值题可按客观要求判，包括等价形式、单位和适用的精度。分步题按关键步骤分别给结果和过程反馈，前一步算错而后一步按所得数值合理推进时，按该卷的实际规则保留过程证据。画图、操作或构造任务评估是否满足约束，接受不同正确画法。作文、实验、代码项目可按具体要求给质性反馈，具备可执行检查时记录实际结果。只在规则定义分值的地方计分。
- 区分未交、识别待确认、评估尚未完成、方法冲突、无法评估及有依据的错误。缺失的步骤或无法定位的失分在学情中保持未知。一个部分判不了时，能确定的部分仍可反馈。成绩、过程质量、帮助曝光和作为掌握度证据的资格分别表达。
- 本人更正改的是被识别的事实，系统据此重判受影响部分。申诉针对正式评估，提交理由后可看到复核状态、新评估及旧评估，复核允许维持原判。本人自评独立保存。重评更新依赖该评估的当前判断与未开始建议，已发任务和旧结果仍能回看。

### 学习证据与效果

- 采集的过程限于学习交互本身：前台活动区间、保存的关键草稿修订、求助/揭答案、跳过/放弃、本人可选信心与自评。缺失用时为未知，切后台不计解题用时；不做全局键盘、摄像头、身体或睡眠监测，不默认逐笔全量录屏。
- 本人自信、本人自评、正式评估分别保存；改自评不改系统评估，申诉产生新的复核评估。受助正确和作品改好均不直接等于独立掌握。
- 题目新颖度与帮助独立性分别记录：原题重做、变式和新情境不能混成同类迁移证据；原题无提示答对可以支持该题记忆，不能直接推出跨情境掌握。权重由具名方法及证据解释，不硬编码“做过即全会”。
- 记录帮助的备好、提供、打开、实际使用、受助完成和后续独立表现。按方法和适用条件比较效果，数据不足不作因果断言，不固化“视觉型”等学习者标签。
- 错后可提议当天换题复测；高信心却错进入诊断候选。间隔由任务与记忆方法决定，不继承旧固定分钟数；学习者拒绝后不变相重推。
- 普通练习与考试均可复盘；迟到错因更新当前复盘与后续安排，保留当时版本。行为推断需多次、相互支持的过程证据，单次快答不能定性乱猜。
- 预测应在结果出现前记录目标步骤、适用条件、时间、预测方法与不确定性，再用可比的后续独立作答对账。优先借用已会出现的学校作业或其他陌生任务。历史回放用于比较方法，预测质量还需未来记录。报告样本量、可预测覆盖和误差，并与近期同类正确率等简单基线比较。
- 评估教学效果还需保留当时可用的选项、系统实际建议、学生选择、收到的教学和后续检查。未选择的课堂、试卷或休息，以及未发生的后测均保留缺失。只有学习者自愿、选项均可接受且没有迫近的截止点时，才可尝试随机比较推荐方式，记录推荐概率，学生可改选。证据不足时仍可以建议下一步，并明确效果待观察。
- 落点：activity 的课堂编排/归档、活动、提交、帮助和过程事实；content 的题目、讲义内容和方法模板；learner 的效果与行为推导；plan 消费结果。教学步骤由会话执行，正式评估仍走所属槽位。
- 验收：渐隐各步可实际完成；检查题进入学习史；提示未显示不记曝光；帮助后原题正确和之后独立变式正确分开；拒绝复测不会换个措辞再次推送。
- 课堂验收：讲义中题目与讲解可连续使用，AI 调整后可继续且保留已发生内容；用后归档可回看当时内容、作答与帮助；题库或知识库后续更新不追改归档，重新编排不覆盖原课堂。

<a id="d05"></a>
## D05 目标与节奏：纳入

### 「今天」可选上课、开练、延后或休息

- 基于实际截止点、兴趣、目标、时间、已锁定活动、已有作业和未来可用的学习机会比较安排。课堂、练习、推迟和留白都在相同的时间与锁定约束下考虑，已知会发生的学校作业纳入每种方案。针对不理解的关键步骤可以建议课堂，已会但迁移未确认可以建议短卷，已有合适的学校作业可以留到那天复习或对账。休息始终可选。无法可靠区分教学效果时，按可解释的时间和证据建议，保留不确定性。
- 每项推荐可打开直接学习的材料，说明要做到什么、为什么此刻值得做、预计用时及来源、推迟会影响什么。预备好的课堂和试卷只有在必要材料、题面和交互可打开时才标为可用。等待付费服务时，优先给当前能做的材料或手动活动。没有合适任务时给出真实缺口和可行的选择。
- 新作答、评估或识别更正、目标与学校进度调整、学习者返回查看等实际需求可触发教研。准备前检查是否已有课、卷、作业或复习覆盖该需要。可复用就复用，有缺口再补。同一需要只显示一份最新可用建议。学生可开练、换选、推迟、拒绝或锁定。这次安排齐备后结束本次备课，三周后回来先做少量能说明现状的摸底，按实际结果重新安排。

- 目标状态明确为进行中、暂停、完成、退出；系统提出“可能达成/可能停滞”及证据，由学习者确认改变承诺。更正或撤销保留历史，不把退出当失败。
- 范围、验收条件、学校进度、考试日期和可用时间由学习者声明；AI 可以提议不能代写成既定事实。数据形式支持预习、学期方向和考后恢复，不要求新学科编程。
- 显式锁定、正在进行和已完成活动受到保护。新安排只替换可调整部分；跨零点保留原活动及未完成工作，不能自动列成惩罚性逾期欠账。目标暂停/完成/退出后停止按旧目标继续备课。
- 自述“累/慌/没兴趣”等有作用范围与绝对失效时刻，默认到本次学习活动时段结束，最迟到声明时学习者时区的当日结束，取先到者；学习者可明确改期限/撤回。耐久会话恢复、跨日和重开聊天不续期，不变成长期能力/人格属性。
- 目标、材料或时间冲突时明确指出无法同时满足的约束并给可选调整，不暗中移动锁定项。安排同时解释预习、复习、补救和探测的选择依据。
- 落点：plan 的目标/约束/承诺事实，learner 的有期限声明，计划和信息量选择是推导。
- 验收：进行中活动跨日不断；改考试范围不动锁定；完成目标后不再自动出题；会话结束后的短期状态不继续影响下一周安排；旧状态可解释可撤销。

## D06 数据自主、删除和恢复：纳入并明确修改历史留存边界

- 用途与保存策略分别表达，提供“仅保存”“学习使用”“仅本轮使用，聊天保留供本人回看”“不留存临时”四个明确预设。首次未确认用途时仅保存；之后交入沿用学习者已确认的默认模式，界面可见、可一键覆盖，不要求逐件分类。不能以缺省 `all` 代替明确用途。
- 仅本轮使用允许本次回答及受控工具调用；原问答保留在原聊天供本人回看，但相关内容及其派生不得进入下一轮上下文、跨聊天检索、摘要、长期记忆、画像或备课。本人打开旧聊天不构成再授权；重新用于计算须明确授权。
- 不留存临时的数据和含其内容的问答、摘要、向量、缓存及执行载荷不进入长期历史。可以在该轮的受控恢复窗口内保存加密临时载荷，完成、取消或失效后销毁其独立密钥与在线副本；恢复窗口有显式到期时间，默认最长 24 小时，不自动延长。保存本轮产物须另行明确确认；界面显示其转为长期保存的范围。
- 外搜默认只发送去个人化的知识/题目需求，不带本人姓名、原话、成绩、私密原件或对话。需要原文的外部处理必须属于已授权用途；未知来源或提供方保留政策不满足所选模式时拒绝外发，不能静默放宽设置。已发生的外部处理不能宣称可撤回。
- 导出包含原件、作品/活动/提交、自评与正式评估、目标、可保存的会话、有效与历史判断、来源/方法、用途、配置及恢复说明。记录导出范围与缺项；临时及已删除内容不借导出复活。
- 永久删除与撤回分开。删除命令必须由学习者明确确认，**不可撤销**；它优先于不可变历史留存，包括原件/所有修订、复制内容、命令与回执载荷、图、摘要、索引/向量、导出暂存和受影响执行载荷。混合来源的产物先不可读，可用未删除的允许输入重算，不能留下泄漏片段。
- 接受删除时先推进删除/访问代次、阻断读取与外发、取消未开始工作并禁止旧候选生效；之后追踪在线清除、执行历史处理和设备确认。回执区分“已阻断”“在线清除完成”“尚有离线设备/备份”，未清完不能显示全部删除完成。Temporal 载荷默认用受控引用；必须保存敏感载荷时采用可按删除范围销毁的加密，不把明文放历史/日志。
- 在线副本清除目标为确认后24小时内，超时报告可处理故障并保持访问阻断，不能将排队当成清除完成。此为工程验收目标，尚未测得；所有对象历史、执行载荷与密钥策略均需纳入实际证明。
- 保留只含随机对象标识、删除代次和必要状态的防复活凭据，不保留原文、摘要、向量或内容指纹。旧设备的旧代次队列不能重新采纳或换新 ID 自动上传；重连先同步删除与访问状态，再恢复其他有效命令。无法联网的设备和已经交给用户的外部副本无法远程保证物理抹除，应明确显示。
- 备份默认最多保留 30 天；立即阻断在线使用不等于已从所有离线备份清除。删除凭据必须独立于可回退的数据快照持久保存；恢复上线前先应用后续删除、用途撤销与外部效果核对，旧 Worker 无提交资格。凭据/密钥无法核对时保持隔离，不能开放读取或自动重放。
- 删除、用途收窄、临时密钥销毁和收费效果发送前身份/状态均有独立于回退快照的防回退凭据、单调水位与完整性证明，不只备份删除记录。敏感动作先登记保护凭据再执行；跨存储失败允许保守阻断，不能产生没有凭据的授权或收费。恢复不能证明凭据完整覆盖恢复区间时，禁止外发、付费重放及旧执行续跑，不以“没有查到撤销”当作仍获授权。凭据仅保留最小控制信息，不复制被删正文或内容指纹。
- 落点：普通用途/导出/删除由内核受控命令发起；清除是内核存储生命周期，不是第四类领域数据或模块 SQL。业务事实/推导仍不可原地改写；**永久删除是明文记录的销毁例外**，见 [ADR-0008](adr/0008-data-lifecycle-and-erasure.md)。
- 验收：仅本轮使用的聊天本人能回看，但下一轮模型读不到；不留存临时结束后本人历史和长期检索均找不到正文；删除后旧设备重连和旧备份恢复均不能复活；取消删除提议无数据变化，已执行删除不可 undo；未知外部结果不被恢复自动重付。

<a id="d07"></a>
## D07 同伴、教研与学习者控制

### 一个同伴，多步行动

- 同伴贯穿题目、阅读、课堂、试卷和自由对话。学生可以用自然语言请它找题、打开旧作、读获准的草稿、比较解法、画图、计算、开一项检查活动、建议调整安排或准备教材修订。读到的依据可打开，写入成功可核对。遇到权限、预算或资源限制，给出当前能做的事和恢复动作。写入用同一套命令。修改本人作品须由学习者采纳，调整锁定的安排须由学习者先解锁。
- 工具从人也能使用的命令和槽位定义获得。会话能根据一个工具的结果选下一个动作，例如检索合适的题、打开候选原文、做独立验算、准备一份可打开的短卷。教研可用同样的能力按工作单后台准备，工作单写明学生需要、交付物和预算。任务结束时核实材料已可用。重复触发复用已有成果，遇阻可查看并停止。
- SSE 渐进显示公开正文、学生能理解的工具进度、通过校验的绘图步骤和已验证的产物。学生可在同一页面看到「在查你上次的解法」「正在核对这道题」「这道题可用」及相应的可打开结果。掉线重连或刷新时恢复有权限查看的已保存进度和产物。后台执行中断后按原工作恢复，已经确认的工具结果和写入可复用，未知收费留待核对。内部推理和未经核实的答案不作为进度发布。
- 长期记忆为有用途、任务适用范围和有效期的独立条目，指向获准的对话或学习记录，区分本人声明和同伴推断。学生可在「我」查看来源、修改、拒绝或撤回，也可在对话中说「以后别再这样用」。新会话和后台教研从当前任务获准的相关摘要开始，需要作教学判断时再打开原作。学生能看到当轮用了哪些记忆和来源。原记录更正后，关联摘要和判断重验。撤回或用途缩窄后，摘要、检索以及恢复中的工作都服从当前权限。短期状态按 D05 到期，能力判断依 D02 的学习证据。

同伴随后台服务自行开始工作。关闭所有界面、结束一轮聊天或清空待办后，它仍可沿自己的发现继续，或主动回看获准的材料和自己写过的作品。服务重启后自行接续。学习者回来时能查看离开期间已经保存的产物、依据和修订时间。后台工作沿用本节的用途、暂停和预算设置。

### 打扰、设置和费用

- 拒绝按目标与建议意图生效，换措辞、刷新、跨日、换模型或新输入版本均不自动解除。默认持续到本人重开；本人可以明确限定为“今天不再问”或选择“条件变化后再问”，只有这种授权的解除条件满足才再提。相近建议合并，非阻塞事项汇总，不要求学习者审批内部每个子任务。
- 进度区分收到、处理、需要输入、可用、部分可用、失败、已取消；失败给重试/更正/换方法/停止等真实可执行出口，不无限转圈。提醒基于实际成果或确需本人决定，默认应用内汇总，系统通知须学习者开启并尊重静默设置。
- 界面采用 Material 3 Expressive。配置集中在同一个设置面板，可配置自定义服务地址和密钥。教学 Agent 固定使用 DeepSeek 4.1 Flash，思考强度为 high。只在服务端保存密钥；更换端点时不能把原密钥随请求交给新提供方。
- 模型设置公开任务档位、首选/后备模型、能力限制、配置来源和每次实际生效的提供方/模型；不能取得真实 served 标识时显示未知，不用请求值冒充。自动后备仅在学习者已允许的能力、用途和费用边界内发生。
- 支出上限按主动请求与后台工作分别设置，子任务共享父预算，未知费用保留占用。尚未设置费用上限时付费后台额度为零；用户可一次设置总额度，之后额度内无需逐项确认。无付费配置仍可使用自带内容、手动活动与确定性能力。
- 落点：learner 配置事实、会话/运行/费用槽位和通用块，实际预算与外发在内核强制执行。
- 验收：拒绝后无同义重推；提醒打开确有成果；配置、实际运行与账单可核对；并行子任务不能各领一份父额度，未知收费不显示为零。

<a id="d08"></a>
## D08 空库首次使用：纳入

- 入口允许一句目标、交入材料、选择内置内容或直接建手动活动；不先要求填学科树、画像问卷、模型配置或完成摸底。
- 有目标和模型时，可共同建立学科语境，准备首个真实可读/可答活动；没有材料时不要求用户先替系统建题库。预测和画像起始为未知。
- 内置一份可审阅、可删除的基础阅读/推理与确定性检查内容包，明确标为内置内容，不冒充针对个人生成。没有模型也能打开、作答、查看确定性反馈，并建笔记/自主学习记录。
- 内置内容不覆盖目标时明确说明，只提供实际可用的自主活动与记录入口；不伪造该学科讲解或个性化安排。选择“仅保存”材料不被偷偷抽取来填满今天。
- 落点：内容包是 content 数据，首次目标是 plan 事实；onboarding 是现有命令与块的组合，无独立用户画像真相库。
- 验收：空库、无模型、无自带材料时仍能完成一个明确标注的内置活动；任意专门目标不被假称已支持；跳过问卷和付费设置仍可进入产品。

## D10 危机支持与转介：范围已定

- 覆盖同伴对话、学习者自己的文本/语音转写、作答与作品备注，以及被学习者确认属于本人的交入内容。引文、题面和第三人称故事不直接当成本人危机；语境不明时温和澄清，不贴诊断标签。
- 仅在本来获准读取且参与该回应/评估的内容上承接支持，不为安全扫描另读“仅保存”材料；尚未识别的图片/音频不能宣称自动覆盖。所有交入、作答、对话入口仍提供显式求助动作。
- 明确表达自伤/自杀想法、正在危险中或近期行为时，优先给予支持，询问眼前安全，鼓励联系可信任的人及当地紧急/危机服务；暂停施压、催练和收费教研，不提供伤害方法。需要地区信息时只问完成转介所需的地区，不猜热线号码。
- 由同一个同伴及既有工具承接，不加所有请求必经的前置 AI 分类/审查链。无模型/离线时保留显式“需要帮助”入口及可离线查看的基础支持说明；不把它宣传为离线危机识别能力。
- 不自动联系家长、老师、警方或第三方，不做诊断或治疗；不创建永久“高危学习者”画像。相关内容继续服从用途/临时/删除规则，外部求助由学习者主动决定，产品不承诺已有人接管。
- 开发负责人对覆盖入口、普通挫败/引用/本人危险的正反例、模型失效出口及外发行为完成独立审查和真实入口验收；不把文字范围已定当作医学有效性或零漏检证明。支持边界参考 [WHO 自杀预防资料](https://www.who.int/news-room/fact-sheets/detail/suicide)，不把学习系统当作专业服务。
- 落点：同伴会话策略、受限求助工具和现有块；不新增危机事实仓库或对话 agent。
- 验收：本人危险表达得到支持及真实转介出口；一道讨论悲剧的阅读题不被硬转危机；未确认不外发，不以后台提醒假称已联系援助；离线按钮可用。

## 2. 实现与完成标准

1. 领域事实由所属模块命令写入；输入清单、用途、更正、生效与预算由内核统一执行。任一新能力必须落入四种模块构件。
2. Temporal 唯一拥有执行进度、重试、等待和并行恢复。PG 同事务 outbox 登记工作意图，稳定 ID 的 relay 允许重复投递；领域工作不是第二套 claim/租约。Python/模型/工具只返回受控产物，不能自认生效。
3. 图、材料、导出与大计算产物使用受控对象引用；Schema 可导出、带版本、跨语言边界校验。没有真实权限隔离时不声称安全沙箱。
4. [BACKLOG](BACKLOG.md) 管理实施依赖。测试代码占全部代码不超过 10%，跨语言统一计数，覆盖 fixture 和支持代码。按实际维护的测试与生产代码计算比例。
5. 完整交付须同时验 PRD 原场景、F01–F73 每个纳入的范围和下面的学生旅程。使用日常产品入口和真实可读、可答的材料，走通适用的保存、重开和继续步骤。用获准保留的材料记录实际交付、操作、结果与未通过的情况。算法的预测质量、教学效果和生产部署各用相应的运行证据验证。

## 3. 明确排除

沿用 PRD §10：多租户、家长/教师端、真人协作端、第二个面向学习者的对话者、公开插件市场、第三方代码运行、身体/睡眠采集、原生客户端、完整离线推理、微服务化和通用工作流编辑器、旧实现兼容与迁移。受控运行学习者交出的程序属于代码评估，和安装第三方宿主插件分开。

另外明确排除被动监听、群聊监控、无证据的数值提分/因果收益承诺与自动联系第三方。它们不是“以后再问 owner”的占位项。算法选择、容量和性能需要实测，不影响这里的产品范围已经决定。
