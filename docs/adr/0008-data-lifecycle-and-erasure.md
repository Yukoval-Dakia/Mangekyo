# 永久删除优先于不可变历史留存

2026-11-17｜accepted。功能范围裁决选择永久删除、临时使用和防复活，而非以追加撤回冒充删除。普通业务事实及推导依旧不可原地改写；本人明确确认的永久删除及预先授权的不留存临时销毁是存储生命周期例外，由内核能力执行，模块不能直接删表。销毁不可 undo，也不引入第四种领域数据或第五种模块构件。

阻断读取/外发/旧候选先于异步清除；所有修订、派生载荷、执行历史和离线副本纳入追踪。无内容的删除/撤权/临时密钥销毁/收费发送前凭据及完整性水位独立于回退快照；敏感动作先登记保护再执行，恢复无法证明完整覆盖区间则保持隔离。不留存临时内容不进入长期历史；仅本轮使用保留本人问答历史但禁止后续利用，二者不能混淆。不能因工作流或收费审计暗存原文。外部提供方已接收内容、未联网设备及外部导出副本的不可控范围必须如实显示。具体见[产品规格 D06](../product-spec.md#d06)。
