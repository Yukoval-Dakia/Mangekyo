# 动态学习环境与认知 v4

2026-11-28｜已采用。

## 背景

现有产品规范已经要求确定性推导、证据可追溯、未知合法、帮助与独立作答分轨，以及自研具名版本化保持算法。现有认知原型仍有综合题多知识点复制计账、受助证据污染、图谱先验缺失、双重衰减和规划魔数等结构缺口。动态学习环境需要把知识形态、局部伸缩、内环响应和微动作练习接到可审计的算法信号上，同时保持内核、模块、Agent 与进程外推导器的既有边界。

## 决定

1. **拒绝粗粒度四大模式切换，采用稳定大桌面与四根连续旋钮。** 学习环境保持安静、稳定的大桌面，由知识形态呈现、单点或单步局部伸缩、30 秒内环微响应、微动作练习曲与活页主体感四根旋钮连续调节。讲解归讲解，活图解专心建直觉，正规题目独立衔接，不往活图解硬塞伪题目。Etude 从真实错步切出 15–60 秒专项微练手，学习者的活页批注和由厚变薄的变化保留为一等体验。

2. **能力与幂律遗忘单源耦合，并强制三态信念契约。** 结构能力 $\theta_c$ 与读时保持率 $R_c(t)$ 分开存储，在对数几率尺度通过
   $$\theta_c^{\mathrm{eff}}(t)=\theta_c+\psi_{\mathrm{KLI}(c)}\ln R_c(t)$$
   单源耦合，禁止对同一证据重复衰减。独立证据与受助证据分轨。每个知识点只能输出 `observed`、`prior_belief` 或 `unknown`，其中图谱、层级和 FIRe 推测只能是 `prior_belief`，不得伪装为 `observed`，也不得在 V1 兼容视图中翻成 `known`。

3. **分离 Colab GPU 离线校准与纯 Python stdlib 在线确定性引擎。** Google Colab GPU 与 PyTorch 只承担群体先验校准、DKT/AKT/FSRS-5 离线标杆对照及合成学生超参扫描，产出经人工评审、版本固定、只读的紧凑 JSON 先验包。线上 `executors/python-deriver/` 永久保持 5–30 ms 纯 Python stdlib、零 GPU、零网络、零 PyTorch、零 numpy/scipy 运行时依赖。FSRS 只作离线参照，生产继续使用自研具名版本化推导。

## 后果

综合题归因、图谱先验、KLI 异构遗忘、选题信息量和环境策略必须由版本化确定性推导器提供，Agent 只负责读取信号并组织教学表达。离线研究需要保存数据集清单、切分哈希、指标、成本、失败运行和先验包评审记录。线上可以读取已入仓的先验包，但不能联网校准或把群体先验当作个人观测。旧版读取保持兼容，生产方法切换仍须通过同样本 Shadow PK、三态、F37、受助污染和区间校准门禁。

## 推翻条件与边界

- 如果 Wave B 的同样本 Shadow PK 未达到预先设定的 Brier、LogLoss、ECE、覆盖率和 F37 门禁，`cognition@4` 保持 shadow，不切换生产默认方法。
- 如果缺少直接独立证据、权限见证、criterion 映射或图谱结构不可辨识，输出必须保持 `prior_belief` 或 `unknown`，不能用兼容视图补成 `known`。
- 如果 Track GPU-Lab 的导出包无法在无网络、无 GPU、无 PyTorch/numpy/scipy 环境中由纯标准库确定性读取，线上接入停止在离线研究边界。
- 本 ADR 不新增领域数据类型、模块构件或 Agent 推理权限。任何超出 PRD §5 四类可写东西、`gather → derive` 协议、模块归属和 `runtime/` 薄透传边界的实现，须另行提出 ADR。
