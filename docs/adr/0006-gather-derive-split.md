# 推导器分 gather 与 derive 两段

每个推导器强制拆成：gather（在控制进程内做记录式读取，产出可序列化输入包）与 derive（纯函数，只收输入包）。

选它因为它同时给出三件想要的东西：推导器可测试（输入包就是样例）、可远程执行（输入包可序列化是协议的前提）、输入清单天然完整（读取只能经 gather 的 ctx，无法偷偷再读）。

边界：固定输入计算遵守此拆分。需要动态再读、工具循环和人工等待的智能属于已有产品需求，由会话宿主经受控读取/效果执行，按 ADR-0007 交 Temporal 恢复；不强行把正常 agent 循环拆成大量槽位，也不向纯 derive 偷开环境权限。
