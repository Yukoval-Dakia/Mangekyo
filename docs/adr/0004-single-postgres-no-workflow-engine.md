# 一个 PostgreSQL，不引入工作流引擎

状态：2026-11-17 被 [ADR-0007](0007-temporal-durable-execution.md) 取代。以下保留当时取舍，不再作为现行实施约束。

事实、推导、会话状态和任务队列都在同一个 PostgreSQL 里。后台执行用以它为后端的任务队列库处理租约与重试，调度什么由内核按过时与需求决定。会话靠逐步追加保存来恢复。

早先设计选 Temporal 作为唯一耐久编排层，并配 Ray、PowerSync 和沙箱隔离。没有采用，因为对一个单学习者、尚无真实使用的产品，这些有状态系统各自的版本、恢复与在途任务语义会成为每个开发者都要懂的东西；而同库带来的直接好处是命令提交与后续工作登记天然同事务。

后果：跨越数月并需按旧代码版本继续的等待、单机跑不完的计算、不可信代码的运行，目前都没有设施支持。各自的引入条件见 PRD §7，引入时不应改动模块代码。
