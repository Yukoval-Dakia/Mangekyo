## 1. 四处核心产品表面 + 随处交入（Material 3 Expressive 响应式 Web）

手机、平板、电脑共用同一套 Material 3 Expressive 响应式界面（375px 窄屏无横向溢出，键盘与触屏完全等价）。**所有新能力必须接入这四处主界面，严禁藏成独立演示页或仅停留在 API/CLI。**

### 1.1 「今天」（动态主行动台）
- **今日编排单**：展示系统按目标、时间预算、学校作业、遗忘紧迫度与锁定项编排好的课堂、短卷、复习或摸底；每项卡片清晰显示：**类型、预计时长、一句话“为什么现在做”（可展开依据）、推迟影响**；只有材料/交互完全备齐的项目才显示“可用”。
- **自主控制**：任意一项支持一键「开始 / 继续」「换一项」「推迟」「锁定」「拒绝（可选今天不问或永久不再提）」；页面始终提供平等的「今晚休息」与「随手开练/翻材料」出口。
- **状态诚实**：显示“不知情知识点”的诚实提示（附一键摸底入口）、正在进行的跨日保护活动、以及后台备课进度（含非阻塞汇总与失败重试/停止出口）。
- **无模型/空库可用**：无模型且空库时直接可开启明确标注来源版本的内置学习包或创建自主活动，不弹强制问卷或付费阻断墙。

### 1.2 「材料」（人与 AI 共用的知识与作品工作台）
四个清晰子视图统一入口，支持任意对象深链直达与刷新不丢进度：
1. **交入原件库**：查看全部照片/PDF/文本/链接/转写，清晰标注「可用 / 处理中 / 需确认模糊处 / 仅保存 / 失败可重试」；模糊处直接在原图局部裁剪框旁一键更正。
2. **智能题库（IQDB）**：支持语义搜索、按知识点/方法/曝光态筛选、单题直接开练、一句话智能组卷、查看问题题原因与更正/停发/重算、生成清洁打印卷与拍回回收。
3. **知识图谱**：按章节/考点/知识点/子技能浏览先修、后继、易混、关联题（预览严禁下发答案）与关联个人教材页，支持教材版本切换映射与知识点合并/拆分回溯。
4. **Notion-like 个人活教材**：多级页面树 + 富块编辑器（Markdown/LaTeX/版本化交互图/嵌入题卡/块级标错/双向反引）；AI 修订以清晰的块级 Diff 呈现在侧栏/行内，支持**分项接受、拒绝或一键撤回**；双端冲突并排展示双版本合并器。

### 1.3 「同伴」（全能对话与协作台）
- **随处带上下文直入**：从任意题、错步、试卷复盘、教材页、知识图谱节点或归档课堂点“问同伴”，自动绑定该对象当前版本与获准草稿进入对话（绝不再要求用户手输 ID 或范围语法）。
- **实时多模态交互**：流式展示正文、可理解工具进度条、逐笔绘制的图形、嵌入式 Generative UI 交互块（操作结果可一键回传同伴）、随堂正式检查卡，以及**所有 Tier 1–2 后台/对话写入的轻量 `undo_token` 一键撤回条**。
- **按需语音**：提供点击触发的口述输入（转写后可编辑再发送）与可随时停止的朗读按钮。
- **记忆透明**：可展开查看“本轮同伴读取了哪些个性化记忆与原证据”。

### 1.4 「我」（全景画像、透明记忆、数据主权与设置中心）
1. **掌握度与校准全景**：按学科/知识点直白展示“稳的地方 / 不稳的地方（含活跃错因）/ 尚不知道的地方”，**每句判断均可点开原提交与当时帮助**，并说明“下次哪种表现会改变判断”；同屏展示事前预测与真实对账校准曲线（含样本量、覆盖率与基线对比）。
2. **它对我的理解（个性化数据透明治理解）**：集中列出 Agent 从全部 6 类活动中抽取出的偏好、声明、短期状态（含倒计时失效时间）、活跃错因、长期断言（`MemoryAssertion` 正反证据）与实证有效教法（`verified_playbooks`），**每条直达源活动证据，支持一键编辑（变粘性）、停用、撤回或删除**。
3. **目标与时间约束**：管理目标生命周期（进行中/暂停/完成/退出）、考试范围与日期、学校进度、每日可用时段与锁定项。
4. **数据主权与用途中心**：管理默认用途预设、单条/批量用途修改、临时模式、全量可携导出与不可逆永久删除进度追踪。
5. **统一设置面板（模型、预算与打扰）**：
   - 集中配置自定义 LLM 服务地址与密钥（服务端加密保存，切端点绝不串发原密钥）、任务档位、默认教学模型（DeepSeek 4.1 Flash，思考强度 `high`）、后备策略、每次真实 `served_model` 与花费明细；
   - 独立配置「主动请求预算」与「后台教研预算」（未设付费后台上限时默认为 0，设好总额度后额度内免逐项审批；并行子任务共享父额度、未知费用保留占用）；
   - 配置静默时段、系统通知许可、暂停/恢复后台教研与同伴人格定制。

### 1.5 「随处交入」（全局快捷动作）
- 四个主界面顶部/底栏常驻快捷交入按钮，支持连拍照片、拖入 PDF/文本、粘贴公开链接、点击口述；界面直观显示当前默认用途预设（可一键切换本次为「仅保存 / 学习使用 / 仅本轮 / 不留存临时」），2 秒内返回回执不阻塞当前阅读。

## 2. 多设备与短暂离线（PRD §2.8 / 单元 18）

- **本地可用**：客户端缓存最近取回的视图与已打开材料（含今日学习单、试卷与教材页）；断网时照常阅读、写草稿、拍新照片、做题交卷。
- **确定性待发队列**：离线命令在客户端创建时生成稳定 `command_id` 并持久化到本地队列（含待上传原件二进制）；离线提交的作答明确标为「已保存，待联机判分」，**客户端绝不本地伪造判分或掌握度判断**。
- **重连幂等同步**：恢复联网后先同步服务端删除与访问代次（防止旧设备复活已删数据），再按序重放待发命令——同一命令重发只生效一次，两台设备分别做的同一道题保留为两次真实提交，教材冲突保留双份绝不覆盖。

## 3. 数据自主、四预设与不可逆永久删除（D06 / ADR-0008 / 单元 34）

### 3.1 四个明确用途与留存预设（绝不用默认 `all` 敷衍）
1. **仅保存**：仅本人可打开回看，任何抽取、题库、学情、画像、后台教研均不可读；公开链接不抓取预览。
2. **学习使用**：授权进入全活动抽取、题库、学情、记忆网关与后台教研。
3. **仅本轮使用（聊天保留供本人回看）**：仅限当次回答及当轮受控工具调用；原问答留在原聊天供本人回看，但其内容及派生**绝对不得进入下一轮上下文、跨聊天检索、长期记忆、画像或后台教研**；打开旧聊天不构成再授权。
4. **不留存临时**：不进长期历史、向量索引与长期记忆；仅在显式到期（默认最长 24 小时、不自动延长）的受控恢复窗口内保存独立密钥加密的临时载荷，完成/取消/到期后立即销毁密钥与在线副本。

- **首次未选时默认「仅保存」**；确认默认策略后后续交入免逐件弹窗，但随时可见可一键改。
- **外搜脱敏**：Exa 等外部检索默认仅发送去个人化的知识/题目查询，绝不外发姓名、原话、成绩或私人原件。

### 3.2 全量导出与不可逆永久删除
- **全量导出**：导出原件、作品/活动/提交、自评与正式评估、目标、可保存会话、有效与历史判断、来源/方法、用途、配置及恢复说明；明确记录缺项，绝不借导出复活临时或已删数据。
- **不可逆永久删除（与可撤销的“撤回”严格分离）**：
  - 必须经学习者明确二次确认，**不可 undo**；
  - 接受瞬间立即推进删除/访问代次、阻断一切读取与外发、取消未开始工作并令旧候选失效；
  - 追踪并清除跨存储全链路：PG 原件与所有修订 + 命令/回执载荷 + S3 对象及历史版本 + 派生摘要/图/向量索引 + 导出暂存 + Temporal 加密引用载荷（明文绝不进 Temporal 历史或日志）；目标 24 小时内完成在线清除，回执诚实区分「已阻断」「在线清除完成」「尚有离线设备/备份」；
  - **独立防复活凭据与单调完整性水位**：删除、用途收窄、临时密钥销毁与收费发送前身份均写入独立于可回退快照的最小控制凭据（只含随机 ID 与代次，**绝不存原文、摘要或内容指纹**）；从 30 天内旧备份恢复或旧离线设备重连时，必须先核对防复活凭据，无法证明凭据完整覆盖恢复区间时强制隔离、禁止外发与付费重放。

## 4. 低打扰、拒绝持久化与危机转介（D07 & D10）

- **意图级持久化拒绝**：学习者拒绝某类推荐或复测后，按「目标 + 建议意图」持久生效——换措辞、刷新、跨日、换模型或新输入版本均**不得自动解除或变相重推**，除非本人明确限定“今天不再问”或“条件变化后再问”且条件满足。
- **危机支持与转介（D10 / 单元 20）**：
  - 由唯一同伴在原本获准读取的对话/文本/转写/作答中承接，**不新增前置 AI 审查链，不另读“仅保存”材料**；
  - 严格区分本人真实危机表达 vs 题面/阅读材料/第三人称悲剧引用；
  - 遇明确自伤/自杀风险时：优先温暖支持、询问眼前安全、鼓励联系可信任的人与当地紧急/危机资源（需地区时只问必要地区，不猜热线号），**立即暂停施压、催练与付费后台教研**，不提供伤害方法；
  - **绝不自动联系家长、老师、警方或第三方**，绝不创建永久“高危学习者”画像；所有主要入口在无模型/离线状态下仍提供显式「需要帮助」按钮与可离线查看的基础支持说明。

## 5. 全量贯通验收总表（Master Acceptance Gate）

产品宣称「完整交付」前，必须全部通过以下 **真实运行证据验收**（隔离 PostgreSQL + Temporal + Python Worker/沙箱 + 真实 Web 浏览器 + 真实模型），**缺任一条不得结项**：

| 验收组 | 必须走通的真实端到端旅程 | 覆盖项 |
|---|---|---|
| **E2E-1 拍卷更正与纸上闭环** | 手机拍 4 页卷（含手写/红笔/1 处模糊/缺 1 页）→ 2 秒回执 → 局部原图一次澄清 → 更正传播判分/掌握度/明日建议 → 生成无答案清洁打印卷 → 手写拍回重传去重 vs 再做留两条 → 补拍缺页不重收 → 另一份“仅保存”卷零越权使用。 | PRD §2.1–2.2, D01, F01–F08 |
| **E2E-2 全活动 Agent 个性化抽取（零正则）** | 普通聊天提作息与讲解偏好（无任何前缀）+ 交卷做错 + 活教材写口诀 + 撤回一次复习单 → Agent 双轨自动抽出偏好/短期状态/结构化错因/长期断言/`playbook` → 进入 `memory-gateway` 生效 → 「我」中点开原证据并一键改/删/撤权生效。 | 02 全章, F39–F45, F63 |
