# 06｜少建层、数据多元复用与「大模块小能力」高阶智能设计

- 定位：对 `00`–`05` 的**架构收敛与智能跃升总章**（Owner 明确裁决：**少建层，让数据多元复用、高效流动；架构上大模块小能力，而不是大能力小模块**）。
- 核心反模式警示：禁止为每个产品想法新建一层抽象、一张新表、一套专属引擎或 5 个碎片小文件（例如把回忆卡、普通卷、后测、课堂切分成互不通气的迷你子系统）。**每增加一项高阶智能，首先问：能否直接复用已有流动数据 + 极薄小能力完成？**

---

## 1. 架构收口：用「少数大模块 + 极薄三层」消灭碎片孤岛

### 1.1 极薄三层（禁止在中间私加新层）
1. **内核统一总线（`kernel`）**：事实库、推导槽位与依赖传播、统一授权/投影/复验读层、命令幂等与效果账本、Temporal 交接。
2. **少数高内聚大模块（`modules/*`）**：领域模型大而统一，同类实体**严禁分裂**：
   - **统一 `Activity` 模型**（`modules/activity`）：单题、练习试卷、独立后测、回忆卡、学习型课堂、聊天检查、作文、代码项目、教同伴、挑刺构题——**共享同一套冻结发放、草稿、提交、过程事实（有效用时/帮助曝光/信心/错步阶段）与同一评估契约**。彻底消灭当前 `recall` / `workbook` / `posttest` / `artifact` 各自一套互不互通的读取与曝光孤岛。
   - **统一 `Content` 知识资产模型**（`modules/content`）：题目（含灵活评估与交互块）、个人活教材块、知识图谱节点与有向边、母题簇、学科语境、版本化方法模板——共享同一套块身份、版本、双向引用与混合检索引擎。
   - **统一 `LearnerUnderstanding` 可质疑理解模型**（`modules/learner` + `modules/companion`）：学习偏好、声明、短期带 TTL 状态、结构化错因、跨科元认知习惯、实证有效教法（`playbook`）、长期断言——**统一采用同一套带 `{ kind, scope, ttl, evidence_refs, sticky, undo_token }` 的事实结构与同一套 `memory-review` 正反核验机制**，绝不为每种理解各造一套表和 CRUD。
3. **Agent 工具与四处表面（`executors` + `surfaces/web`）**：人、同伴、前哨与后台执行者消费**完全相同**的底层数据流与 10 窄核心工具，不造平行通道。

## 2. 「一份数据、多元复用」高效流动矩阵（Data Poly-Reuse Matrix）

系统里每一类核心原始事实只写一次，零拷贝流向多个消费场景，形成复利：

| 统一原始事实（只写 1 次） | 多元复用的消费场景（零重复采集、零新中间层） |
|---|---|
| **统一提交 + 过程事实**（题源、原答、原位草稿、有效用时、帮助曝光、信心、五阶段错步） | ① 自研多维掌握度与读时遗忘引擎 ② 结构化错因档案与跨科元认知模式 ③ 高信心错答“反掌握幻觉”探测 ④ 考场时间分配与策略复盘 ⑤ 事前预测对账 & 教学干预有效率评估 ⑥ 双通道 Backtrace（错法+成功法） |
| **原件与题目/图谱事实**（多页校内卷、母题关联、语义标签、活教材块） | ① 直接开练 / 一句话组卷 / 清洁打印拍回 ② 课堂嵌入与 Generative UI 交互 ③ 多套卷自动母题折叠（学 1 道顶 10 道）④ 活教材自动知识压缩与考前急救卡 ⑤ 用“已稳旧题/旧概念”桥接新知识 |
| **统一可质疑理解事实**（全活动 Agent 抽取：偏好、TTL 状态、错因、元认知、有效教法） | ① 同伴实时讲法与画图偏好 ② 前哨分诊（疲劳退让/错因补救/考前冲刺切换）③ 动态「今天」与组卷约束 ④ 知识库园艺与重复清理 |
| **运行与工作流事实**（`facts` + `working_todos` + `runs` + 费用账本） | ① 预算控制与防超支 ② 服务重启无缝恢复 ③ 「我 → 决策因果追踪台（Decision Trace）」直接投影展示（不另建日志子系统） |

## 3. 六项高阶智能——全部以「小能力（Thin Capabilities）」零新层落地

以下 6 项能力将产品智能拉到极致，但**严禁做成重型独立子系统**，每项仅通过“复用统一数据 + 极薄字段/投影/Agent 策略”落地：

### 小能力 1：五阶段错步分类 ＋ 原位草稿分叉点诊断
- **薄数据扩展**：在统一评估与错因结构上增加标准 5 值枚举 `error_stage: 'reading' | 'modeling' | 'strategy' | 'execution' | 'expression'`（审题漏条件 / 概念模型错 / 思路卡壳 / 计算笔误 / 表达规范丢分）；在统一活动作答草稿上支持轻量步骤/画板草稿字段 `scratchpad`。
- **智能效果**：五种错步自动导向不同处方（计算笔误不推概念课，概念错不狂刷计算题）；学生在做题页草稿区点“看我卡哪了”，同伴直接定位**“前 3 步全对，第 4 步分叉在这里”**。

### 小能力 2：跨科元认知共性病根 ＋ 击穿「掌握幻觉」
- **零新表、纯复用**：
  - 异步抽取 Agent 在跨科活动切片上直接产出 `kind: 'metacognitive_habit'` 的统一理解条目（如“审题常跳读限制词”“边界条件漏检”，必须跨至少 2 科或多次独立证据才成立），开卷前轻提示 1 句；
  - 前哨与规划器直接消费统一提交里的 `(confidence=high && result=incorrect)` 信号，对高信心错答区优先派发**最小反例辨别题**击穿掌握幻觉。

### 小能力 3：校内卷母题折叠 ＋ 考场时间策略复盘
- **零新引擎、纯复用 `save_relation` + Python 沙箱**：
  - 拍入多套校内卷/真题后，后台 Agent 用现有 `search_learning` + `save_relation(kind='canonical_archetype')` 把 50 道表面不同的题折叠成少数核心母题与变形维度，在材料与「今天」中标出“学透此母题覆盖 N 道原卷题”；
  - 整卷复盘直接用 Python 沙箱读取同一批作答的 `effective_duration_ms + score`，一键生成**考场时间策略诊断**（例如指出在某压轴题过度耗时挤压了后面可得分的中档题）。

### 小能力 4：进攻性融会贯通（自动知识压缩、挑刺构题、旧稳桥接）
- **全部组合现有工具与 `Activity`**：
  - **自动知识压缩**：一章累计多条错因/零碎笔记后，后台 `heavy_tutor_prep` 用现有 `save_page(patch)` 自动在个人活教材顶部维护 **1 页“决策树 / 易混对比表 / 考前 3 分钟急救卡”**（带 `undo_token`）；
  - **高阶反向活动**：不新增引擎，直接用现有 `Activity + IQDB` 通用 Schema 发出**「给伪解答挑隐藏漏洞」**与**「造反例/改坑题」**两种高阶迁移活动；
  - **旧稳桥接新知**：同伴讲新概念前，直接用 `search_learning(mastery_gt=0.8)` 找该生**真正彻底掌握的旧题/旧概念**做个性化类比。

### 小能力 5：教学干预有效率闭环 ＋ 低频知识库园艺（KB Gardening）
- **零新账本表**：
  - 直接通过 `activity`（帮助/讲义/课堂使用记录）与后续独立提交的关联查询，算出不同教法对该学习者的实际有效率，自动把实证有效的策略写入统一理解的 `kind: 'verified_playbook'`，淘汰“打开率低且无提升”的冗余形式；
  - 后台教研在低预算空闲窗口顺手执行 **KB 园艺**（合并重复零散笔记、清理过期草稿、核对矛盾 `MemoryAssertion` 与悬空题-页引用，全量 Tier 1–2 带 `undo_token`）。

### 小能力 6：现实体验三件套（宏观战役态、碎片单手模式、延迟路由与决策 Trace）
1. **三大宏观战役态（仅作用于规划/前哨策略参数，不建新引擎）**：根据 `modules/plan` 中现有考试 DDL 自动或手动切换——**日常稳步** / **考前冲刺（T-7 天聚焦高频母题、急救卡与限时模拟）** / **考后复盘减压（区分预料内与意外失分，不压新任务）**。
2. **碎片时间与单手零输入筛选**：`today` 视图直接按时长（`3min / 15min / 45min+`）与输入方式（`单手点选/口述`）过滤统一 `Activity` 候选，通勤 3 分钟也能做断句、方法辨析或挑刺题。
3. **四档延迟与成本路由硬 SLO + 决策因果 Trace**：
   - 确定性交互/草稿/读时遗忘计算 **<150ms（0 LLM）**；同伴首字 **<1s（预备解答 + 热缓存前缀）**；前哨分诊与异步个性化抽取强制走**便宜快模型**；仅深度诊断、难题多解验算与复杂讲义动用高思考强模型；
   - 「我 → 系统运转」直接投影现有 `facts + working_todos + runs`，折叠展示任意推荐或备课的完整因果链（`源事件 → 命中 Skill → Todo → 工具与实际模型/费用`），零额外埋点层。

### 小能力 7：学习中断「10 秒无痛续场卡（Resume Breadcrumb）」
- **零新表、0-LLM、<150ms 复用**：学习者日常频繁被打断（吃饭、上课、隔天续做），重进未完成的题目/试卷/课堂时，直接复用统一 `Activity` 已有的 `scratchpad` 草稿修订、`current_item_id`、已展提示记录（`help_exposure`）与最近 1 条 `Turn` 锚点，在距离上次操作 >20 分钟重入时，于顶部轻浮 1 条可一键收起的单行续场条（如`上次停在第 3 题 · 已展提示 1 · 草稿停在“设 u=x+1” → [继续这步] [盖住重做]`）。
- **数据双用**：点 `[继续这步]` 原位滚动聚焦草稿框（零额外导航）；同伴首轮 JIT 锚点槽直接复用同一续场指针，彻底消除“回想刚才做到哪”的心流断层。

### 小能力 8：错题「临界微卡点徽章 ＋ 30 秒同壳换数验证（Near-Miss Recovery Chip）」
- **零新表、复用 `error_stage + Edge(variant_of) + work(scheduled)`**：
  - 历史作答与错题卡片标题旁，以 **0-LLM 极简徽章**直接投影 `Evaluation.error_stage`（如`审题漏条件 / 思路卡壳 / 计算笔误`）＋ 1 句原位分叉点摘要，一眼看清离做对只差哪 1 个动作；
  - 订正或听懂后，题尾提供 1 颗低摩擦按钮 **`[30秒来1道同壳换数验证]`**：0-LLM 从现有 `Edge(variant_of / canonical_archetype)` 池中秒取 1 道未曝光同构微变式（池空时轻挂后台 `question_author` 并预约 24h 后 1 题短回测 `work(scheduled)`）；独立做对即刻触发域 3 的 0-LLM 正向反证更新，让“刚听懂”立刻转为可验证的独立掌握。

## 4. 本章反糊弄验收（专门防“叠层与碎片化”）

1. **大模块收口验收**：回忆卡、练习卷、独立后测、课堂随堂检查必须共用同一套 `Activity` 曝光/用时/提交读取原语，**禁止**为每种活动形态复制一套独立的读取、授权与曝光表/服务。
2. **数据一写多用验收**：提交一份带有效用时、高信心标记与草稿的作答后，同一份原始事实同时被（a）多维遗忘引擎、（b）五阶段错步归因、（c）高信心反幻觉检测、（d）考场时间复盘与（e）`memory-gateway` 消费，无需二次抄写或同步拷贝。
3. **延迟路由与 Trace 验收**：核对真实运行账本——简单交互与读时遗忘为 0 LLM 调用、前哨与异步抽取确走便宜模型；在「我」页面可点开任意一次后台备课或推荐的完整因果链并核对实际模型与费用。
