## 1. 全渠道随处交入与分层个性化抽取（`modules/capture`）

### 1.1 交入入口与回执契约
- **随处可用**：在「今天 / 材料 / 同伴 / 我」四处任意界面均可一键交入，无单独强迫表单、不强制选学科或题型。
- **支持源类型**：
  1. 多页拍照 / 图片集（手机连拍四页卷子、作业、白板、草稿纸、群截图）；
  2. PDF / 文档 / Markdown / 纯文本；
  3. 公开 URL（**仅保存模式绝不发起外部抓取**；学习使用模式下经用户明确“读取链接”才抓取，受限/登录/付费墙/内网地址返回真实失败，禁止凭标题捏造正文）；
  4. 按需语音口述（前端录音→转写→**可编辑确认后**才作为正式文本入库；默认不保存音频原件，仅当用户显式勾选“保存音频原件”才存 S3；绝不做常开麦克风或被动监听）。
- **两秒先回执、零阻塞**：`capture.ingest` 写入原件事实（对象存入受控存储并记录 `sha256 / mediaType / size / purpose / retentionPolicy`）后立即返回回执，学生可立刻锁屏离开。**后续抽取、解答、判分全走异步 Temporal 工作流，失败绝不删除原件。**

### 1.2 多模态分层抽取（彻底替代当前“整页纯文本 OCR”）
对每一份获准用于学习的原件（图片/PDF），抽取推导器（支持多模态视觉模型 + MinerU/文档解析协同）**必须输出结构化分层结果**，并携带每块的精确原图坐标 `bbox`（支持 `open_learning(part="image_crop")` 原图回看）：

1. **印刷题干与共享材料层**：
   - 保留完整共享长材料（如语文阅读、物理大题背景图）、子题树（`(1)(2)(3)`）、多作答位、LaTeX 公式、选项与图表坐标；跨页材料自动拼接并保留页码锚点。
2. **本人原始手写作答层**：
   - 识别学生原始手写过程与答案，挂接到对应题目与作答位。
3. **红笔 / 事后订正与教师批注层**：
   - 独立识别红笔字迹、勾叉、评语与事后订正；**结合学习者个人偏好**（如“我的红笔是事后订正，不算首次作答”）单独归类，**严禁把红笔订正混算为首次独立作答**。
4. **参考解答与评分规则层**（若卷面自带）：
   - 单独标明出处为“学校/原卷自带”，与系统独立求解结果分开存放。
5. **诚实的「未知」与一次澄清**：
   - 任一涂改、模糊、截断处必须输出 `status: "unknown"` + `crop_ref`（局部原图切片）+ 可选候选值（如 `["0.5", "0.8"]`），相关判分槽位进入 `waiting`（**绝不先猜分**），对同一处只问学习者一次。
   - 学习者在卡片上直接看到局部原图，点选或手填更正 → 触发 `capture.correctExtraction` 生成新修订（作者=`learner`，保留旧修订）。
   - **粘性与传播**：学习者更正过的字段标记 `sticky`；后续用更强模型重抽该原件时，只能提出差异提议，绝不静默覆盖本人更正；同时内核依赖自动令旧判分、掌握度与未开始安排过时并重算，旁注“因为你更正了第 X 题”。

### 1.3 纸上学习完整闭环（打印清洁卷 → 手写 → 拍回匹配）
- **生成可打印清洁卷**：
  - 从任意安排、试卷、教材或知识点生成打印版（PDF/打印视图），长材料完整跨页、公式与图清晰可读，禁止靠裁切或缩成蚂蚁字凑版面。
  - **严格清洁防剧透**：清洁练习卷的文本层、隐藏元数据、附件和定位码**绝对不得包含参考答案、解答或评分规则**；答案版须由用户另行显式生成。
  - **稳定身份与定位**：打印件附带不含答案的 `issuance_id` + 页码/题位锚点；同内容重印复用原 `issuance_id`，冻结内容变化则生成新 `issuance_id`。
- **拍回匹配与部分回收**：
  - 拍回照片优先匹配原 `issuance_id` 与对应题目；匹配不确定时列出候选原任务由学习者确认，**严禁猜测合并**。
  - **幂等 vs 再做**：同一回收图片重复上传凭稳定标识去重，只落一次提交；明确“再做一次”则创建新的真实提交记录（不覆盖旧提交）。
  - **缺页合法**：漏拍一页时，未交题保持 `unsubmitted / unknown`（**绝不计 0 分**）；回家补拍只补齐缺失题目的提交，不重复收取已交页。
- **立即可练**：刚交入并抽取完成的单题即可直接开练，不必等待整卷全部判分或明日规划完成。

## 2. 智能题库（IQDB，`modules/content`）

智能题库不是静态题目表，而是服务于**“此刻给这个学习者看哪道题，收到什么回答后值得改变下一步”**的语义决策库。

### 2.1 通用题目 Schema（一套契约容纳万千题型，新增题型 0 代码）
每一版题目（`content.question`，不可变版本化，发入活动时冻结引用）包含：
1. **内容与结构**：出处与用途、完整题干、共享材料引用、子题层级、图表/媒体句柄、交互块定义（见 `03` Generative UI）。
2. **作答位声明（`response_schema`）**：明确正式提交的精确结构——单选/多选、数值+单位+精度、分段/多空、纯文本/公式、字间位置集合（如文言文断句，与字号换行无关）、网格/时间轴落点（如音乐两声部节奏鼓机）、画图几何对象、代码文件、附件照片等。
3. **解答与脚手架包**（交卷/求助前对客户端硬隔离）：
   - 已核验标准解法 + 等价替代解法列表；
   - 关键步骤拆解与部分得分点；
   - 分阶提示（L1 方向 → L2 关键步 → L3 局部示范，可逐阶解锁）；
   - 配套最短辨别题（用于区分解法是否真正掌握）。
4. **随题冻结的灵活评估契约（`assessment_contract`）**：
   - 声明读取哪些提交字段、调用哪种判分方式及其版本号与参数（可组合）：
     - 确定性规则（数值等价/单位换算/集合匹配/多套合法断句方案取单套最高分、禁止跨互斥方案拼满分）；
     - 关系与约束求解（如画图或两声部鼓机“各 3 击且交集恰为第 1 格”——容许无穷多等价满分作品）；
     - 模拟器/隔离代码运行器（跑测试用例、Python/SymPy 符号验算）；
     - 冻结评分标准下的 LLM 评阅（结合 Python 验算与获准 Exa 检索，逐项引用学生原答片段给理由）。
   - **自验收标准**：出题 Agent 仅用现有 schema 创作一道系统从未硬编码过的新题型（如文言断句或两声部鼓机），存库后另开练习能完整渲染交互、收提交并精确判分（通过两份不同满分作品 + 一份差一条件的部分分作品）。

### 2.2 精确可溯源语义标签与变式族谱
- **四层分离标注**（每条标签附出处、适用范围、版本与核验态）：
  1. `target_skills`（本题真正要观察的核心目标技能）；
  2. `prerequisites`（完成所需的先修能力，如单位换算）；
  3. `optional_methods`（可选解法路径，如图像求面积 vs 代数联立）；
  4. `discriminators`（表征形式、关键条件、易混方法、干扰项指向的待核查错因线索，以及**区分解法所需的最小条件改变**——例如“等时两段速度 30/60 均得 45 无法区分直接平均与加权平均，改第二段为 2 小时才分离”）。
- **变式族谱（`question_relations`）**：显式记录两题关系（同源/译本/仅换数字/改单一关键条件/跨表征迁移/易混对照），并标明**是否会剧透同族题解法**。
- **接触史分离**：题库只存共享内容；学习者接触过哪版、做过几次、看过哪阶提示、是否见过同族完整解法，全部存在 `activity` 中，选题时合读两边。

### 2.3 Agent 找题、缺口补题与题库自治理
- **目的驱动找题**：Agent 可按复杂教学意图检索（如“3 分钟内、能区分直接平均与时间加权、只改一条件、未暴露同族解法”）。先执行用途/可发放性/接触史硬过滤，再结合语义标签与向量召回，最后**打开实际题面与解法**拍板，记录“为什么选它”与“为什么淘汰其他候选”。
- **诚实缺口与自动补题**：
  - 优先复用学习者获准材料与已验证题；
  - 若缺口明确（例如“3 道库内题里 2 道无法区分解法，1 道昨天已看解析”），先如实报告缺口；
  - 获准后由 `question_author` 生成候选新题，**强制经过独立双解/三解并行验证**（答案、单位、隐含条件、等价解法、必要时 Python/SymPy 验算），一致才转 `ready` 进入题库；冲突绝不冒充可用。
- **题库自治理**：
  - Agent 可发现重复题、提议合并同义标签或拆分含混标签、标出答案冲突/条件不足，按具体用途降级（例如某题暂缓用于“区分方法”，但仍保留作“等时段例题”）；
  - 问题题必须可见具体原因并提供“更正 / 重算 / 停发 / 撤回”入口，**严禁从列表静默隐藏**；修正后自动重算受影响判分与未开始备卷，已发历史卷仍按冻结版回看。

## 3. 知识图谱与学科语境（`modules/content`）

- **学科是数据，不是代码**：新增一门从未内置过的学科（如 Python 递归、音乐乐理、日语古文），由同伴与学习者共同起草 `discipline_context` 事实（学什么、怎么算会、如何评估与客观边界），**0 行代码即可运作**。
- **多跳有向知识图谱**：支持教材章节、考点、知识点、子技能、方法、适用条件与题目之间的双向导航；关系包含 `prerequisite`（先修）、`successor`（后继）、`confusable`（易混）、`transfer`（迁移）、`variant_of`（变式）、`maps_to_chapter`（教材章节映射）。
- **关系不自动授予掌握度**：知识图谱组织内容，学习判断只认真实活动证据。
- **换教材、合并与拆分不丢史**：
  - 教材换版只新增版本化章节映射，绝不重建清空学情；
  - 合并知识点保留旧 ID 重定向与原学习史；拆分知识点时，旧粗粒度证据保留在父/历史归属下，不虚构细分掌握度。

## 4. Notion-like 个人活教材与双向草稿协议（`modules/content`）

- **AI 主导持续维护 + 学习者随时批注编辑**：
  - 个人教材按 Notion-like 页面树组织，页面粒度由内容自然决定（一个关键细节或易错点也可独立成页）；
  - 页面由**稳定 `block_id` 的富块**构成：Markdown/LaTeX 块、版本化交互图/Generative UI 块、嵌入题卡与随堂检查块、引用块、反向引用、块级标错；
  - **双向可打开关联**：题目页列出关联知识点与教材页，教材页反向列出关联题与本人历史错题/作答，点击均直接打开对应对象（预览严格防剧透）。
- **活教材演化与局部 `patch`**：
  - AI 新起草独立讲义：先落 `content` 草稿槽位，成为独立可编辑页时经采纳命令创建事实（Tier 2 直落带 `undo_token`）；
  - AI 修改**学习者编辑过的页面**：必须通过 `block_id` 局部 `patch` 生成**块级可分项采纳/拒绝/撤销的 Diff 提议**（一块失败不吞其余块），严禁整页重写或静默覆盖本人编辑。
- **双端草稿与冲突保护**：
  - 活动作答草稿（`activity`）与教材编辑草稿（`content`）均携带明确 `base_rev` 与客户端递增编辑序号；
  - 迟到的旧保存回执绝不覆盖更新的本地草稿；
  - 两设备并发修改同一页时，**保留两份冲突版本并提供清晰合并/选择入口**，严禁按时间戳 Last-Write-Wins 吞稿。
- **历史冻结**：旧聊天绑定当时的页面/图版本，重开旧聊天仍看到当时的图与讲解，后续修订教材绝不追改历史对话。

## 5. 本域禁止糊弄清单与硬验收矩阵

### 禁止糊弄清单
- ❌ 禁止把 `intake` 停留在“纯文本 OCR 全文粘贴”，必须做印刷题/手写/红笔/未知分层抽取与局部原图裁剪澄清。
- ❌ 禁止清洁打印卷携带答案或评分规则文本层。
- ❌ 禁止把新题型写死在前端 `if (type === 'sentence-break')` 分支里；必须走通用 `response_schema + assessment_contract` 驱动。
- ❌ 禁止生成题跳过独立多解验算直接入库。
- ❌ 禁止 AI 修改用户教材页时直接整页覆盖或绕过分项 Diff。

### 硬验收矩阵
1. **四页拍卷→缺页补拍→手写更正→红笔分离**：手机拍 4 页卷（含 1 处模糊手写 + 1 处红笔订正 + 缺 1 页）→ 2 秒内出回执 → 模糊处只问 1 次并展示原图裁剪，更正后判分/掌握度/明日建议联动更新；红笔不计首次作答；补拍缺页不重收已交页。
2. **清洁打印→拍回重传去重 vs 真实再做**：长阅读跨两页完整打印，清洁版无答案层；拍回重传同一照片仅 1 次提交，明确重做产生第 2 次提交。
3. **无内置代码的新题型闭环**：Agent 创作一道两声部节奏鼓机题存入题库 → 另开练习完整交互并提交两份不同满分作品 + 一份差一条件作品，均精确判分并指向具体落点字段。
4. **「同一个 45，两份不同学习史」**：按 [intelligent-question-database.md](../design/intelligent-question-database.md) 首项验收，真实 Agent 读取两份不同历史后分别决定跳过追问或精确选择改时长变式；移走最后一道合格变式后如实报告缺口并触发独立验算补题。
5. **活教材双端冲突 + 局部 Diff**：两设备改同一页保留双版本；AI 提议改 3 个块，用户接受 2 块拒绝 1 块，且历史聊天仍冻结旧图版本。
