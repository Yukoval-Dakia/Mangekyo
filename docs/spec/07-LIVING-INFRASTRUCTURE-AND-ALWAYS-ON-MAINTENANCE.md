## 1. 四齿轮能力回环（大模块小能力的运行铁律）

任何复杂产品能力都不靠堆新层/新子系统实现，而是由以下 **4 个齿轮在单一 `kernel` 总线上咬合运转**：
1. **① 数据（全源统一事实流，只写 1 次）**：站内统一 `Activity`（做题/后测/草稿/课堂/聊天/用时/曝光/撤回）+ `modules/capture`（拍卷/PDF/公开链接/按需语音/**Notion 只读扩展**）+ `modules/content`（题库/活教材/图谱）。
2. **② 个性化（全活动 Agent 抽取，零正则）**：统一 `{ kind, scope, ttl, evidence_refs, sticky, undo_token }` 可质疑理解模型，由 Agent 跨全部活动源持续提炼、强化与反证。
3. **③ 计算\*（确定性 / 统计 / 符号 / 沙箱算力，0 幻觉）**：独立 Python Worker 与隔离 Python 沙箱承担自研遗忘 `R(t)`、信息量与时间约束求解、预测校准与 Shadow 重放、跨卷母题与耗时统计、SymPy 验算/精确绘图（`@calc_*`）与真实学生代码评测。
4. **④ 智能（两层 Agent + 10 窄工具，只做高价值拍板）**：便宜前哨分诊 + 强力主 Agent/后台执行者读取真实题目、Notion 笔记与计算\*硬结论行动（Tier 1–2 直落带 `undo_token`），每次真实交互反馈立刻回流 ①。

## 2. Notion 只读扩展规格（零新层接入 `modules/capture`）

- **授权与边界**：
  - 在统一设置面板支持配置 Notion OAuth / Integration Token（密钥仅存服务端，切换源绝不串发原密钥），支持精确选择授权的 Page / Database（如课堂笔记、课表/DDL 库、错题/读书摘录）。
  - 严守 D06 四用途预设（仅保存 / 学习使用 / 仅本轮 / 不留存临时）；撤销 Notion 授权或移出页面权限后立即阻断读取并令依赖派生过时。
  - **默认严格只读**：绝不未经明确确认反向修改用户 Notion 原库（Mangekyō 活教材在站内独立演化；未来若支持写回仅作显式导出或 Tier 3 确认）。
- **双通道读取（不造第二真相库）**：
  1. **增量只读快照入 `capture`**：按 `notion_page_id + last_edited_time` 游标增量拉取获准页面、子块与 Database 行，写入 `capture` 原件事实，自动复用统一 PG 混合检索、块引用、全活动 Agent 抽取与知识图谱对齐；
  2. **按需实时直读**：经 `find_tools` 按需暴露只读 `notion_read` 工具，当同伴或后台教研遇到刚编辑过的页面时实时拉取最新块。
- **跨源互联价值**：Notion 课堂笔记一旦入流，即刻与站内题目、错因、动态「今天」（读取 Notion 课表/DDL）和活教材打通（例如同伴在讲解错题时直接引用学生自己写在 Notion 笔记里的类比段落）。

## 3. 四块「活基础设施」地基原语（让未来加能力 0 阻力）

### 地基 1：一等规范实体 ＋「先对齐、再新建（Link-Before-Create）」
- 知识点（`content.concept`）、方法、错因、母题均为带稳定 ULID 身份的独立规范实体，具备：`canonical_name`、`aliases[]`（中英文/缩写/教材章节名）、语义向量与 `merged_into`（合并后永久重定向，绝不丢任何历史关联）。
- **统一实体解析原语（Entity Resolver）**：无论来自题目、Notion 笔记、PDF 讲义还是聊天，抽取器产出候选概念时强制先过「精确别名 + `pg_trgm` + 向量 Top-K」召回：命中直接挂同一 `concept_id`；语义接近由 Agent 结合上下文判别；仅确认无匹配时新建。

### 地基 2：跨源一等双向关系图谱（Unified Typed Edges）
- 所有资产（题目、Notion 笔记块、拍卷原件、活教材块、历史作答）通过统一 `ref` 以一等有向边连向规范实体（附 `relation_kind / basis / author / confidence`）：
  `题目 A ──[tests]──▶ concept_id ◀──[explains]── Notion 笔记块 B`
- 对齐到同一 `concept_id` 即天然 2 跳双向打通：做题自动露出 Notion 课堂对应段落，翻 Notion 笔记自动露出相关题与掌握状态。

### 地基 3：「冷历史（Facts）」与「活外衣（Living Derivation Slots）」严格分离
- **永不篡改的冷核心（Facts）**：当时冻结题面、原答、原图、有效用时、当时帮助曝光——永久真实留存。
- **持续演化的活外衣（Living Slots，全部带 `deriver_version` 与输入清单）**：
  - **旧题目活外衣**：知识点归属、先修/易混标签、母题簇、随真实作答持续校准的预计用时与辨别力、新增等价解法与分阶提示；
  - **旧作答活外衣**：五阶段错步分类、结构化错因归因、拆分/合并后的最新知识点挂接、基于后续新证据的**回溯性再解读**；
  - **粘性保护**：本人修改/确认过的标注标为 `sticky`，自动重算只提差异提议不覆盖；历史版本推导仍可回看。

### 地基 4：反查依赖索引 ＋ 版本水位 ＋ 热/温/冷渐进回填调度
- 内核提供一等查询：按实体变更反查所有依赖旧题/旧作答/Notion 块/活教材；按 `deriver_version` 水位查询待升级旧槽位。
- 四类自动再维护触发：图谱拆合、跨源新洞察回溯旧错题、模型/推导器升版、新真实作答校准。
- **热 / 温 / 冷三级调度（防重算风暴）**：
  - **热对象（立即重算）**：当前活跃章节、考纲范围、刚打开的题与近 7 天作答；
  - **温对象（空闲低预算攒批回填）**：按价值排序（活跃错因相关 > 高频母题 > 普通近期历史）分批升级；
  - **冷对象（惰性升级，0 浪费）**：久远非活跃记录仅标 `behind`，平时不花钱，被检索或打开时按需刷新。

## 4. Always-On 全域发现与全面维护升级

### 4.1 编排收口为 4 大任务家族（便宜前哨可稳定驾驭）
1. **即时响应族（Reactive）**：同类错因复发、**高信心错答（错 1 次即触发反幻觉最小反例题）**、考期/目标突变重排、疲劳/撤回/连续跳过退让与调粒度。
2. **前瞻供给族（Proactive Prep）**：遗忘 24–48h 滑坡前预备复测、**考纲 `unknown` 空白摸底**、**题库变式弹药枯竭预补**、每日「今天」与 T-7 冲刺态切换。
3. **跨源汇流与压缩族（Synthesis）**：Notion 新笔记/新卷增量同步触发跨源连边与旧错题回溯重解；章节做熟后自动压缩 1 页急救卡/决策树与母题折叠。
4. **活资产维护与自进化族（Living Maintenance）**：图谱演进与模型升版温数据回填、资产园艺（重复笔记/重复概念/矛盾断言/问题题/断链）、过期未使用库存清理、教法干预有效率复盘与 Skill `when_not` 进化。

### 4.2 补齐 4 项关键维护机制（零新层）
1. **慢变量「资产健康与机会雷达」**：在 `mangekyoCoordinator` 热快照中增加由 0-Token SQL/确定性查询产出的紧凑区块（6 个指标 + Top-3 句柄：`unknown_exam_gaps`、`high_conf_misses`、`supply_shortages`、`warm_backfill_queue`、`asset_entropy_candidates`、`stale_unused_inventory`），配合每日空闲窗口 `recheckAtMs` 自动巡检。
2. **补齐 4 类全域维护原语**（纳入现有窄工具/领域命令，不另造子系统）：
   - 活教材跨页重构（合并碎页、拆分子页、归档过时页）；
   - 题库与图谱存量演进（合并重复概念/题并保留永久重定向、拆分粗概念触发旧题重挂、向旧题活槽位追加等价解法或按用途降级）；
   - 旧作答活外衣刷新（严禁改冷原答，仅允许刷新诊断/错步/错因/知识点挂接槽位）；
   - Notion 增量变更游标接入前哨唤醒。
3. **两级优先级与 20% 维护预算硬隔离**：前台伴学与核心备课永远最高优先；温数据回填与 KB 园艺独立限额（≤ 后台总预算的 20%），学习者上线交互时低优维护立即让路。
4. **按「可逆性 × 影响半径」划分 3 档维护自治权**：
   - **绿灯直落（全自动 + `undo_token`）**：只读连边、刷新旧题/旧作答活推导槽位、补题验算入库、更新 AI 自建讲义/急救卡、清理过期未使用库存、明显别名归一化（留重定向）；
   - **黄灯批量汇总（非打扰，收进「待审园艺清单」一键勾采纳）**：拆分粗概念、合并用户编辑过的多篇笔记、停用存疑旧题、对粘性标注提议更正；
   - **红灯显式确认**：改动目标承诺/锁定项、覆盖用户原创正文、永久删除、超预算外调。

## 5. 本章硬验收标准
1. **题目 ↔ Notion 笔记跨源自动连通**：授权 1 篇 Notion 课堂笔记（使用与题库不同的同义表述）→ 经实体解析对齐到同一 `concept_id` → 2 跳自动关联站内对应题与旧错题；撤回 Notion 授权后立即失效不泄露。
2. **旧题与旧作答活维护不冷冻**：对已存历史题和旧作答分别验证（a）拆分知识点后热/温旧题旧作答自动重挂新子技能，本人 `sticky` 标注不被覆盖；（b）标注器从 `v1` 升 `v2` 后，热对象立即刷新、温对象在 ≤20% 预算内分批回填、冷对象标 `behind` 零消耗待按需刷新；（c）历史原始作答与当时冻结题面纹丝不动。
3. **Always-On 慢变量发现与 3 档自治**：在无新实时事件状态下，空闲巡检通过慢变量雷达真实发现「考纲 `unknown` 空白」「题库弹药=0」「重复笔记/过期库存」三类任务并按绿/黄灯分级处置，前台新请求到达时低优回填立刻让路。
