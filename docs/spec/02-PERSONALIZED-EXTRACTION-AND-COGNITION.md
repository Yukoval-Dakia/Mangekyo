## 1. 彻底清除正则 Slop，确立全活动 Agent 抽取原则

### 1.1 强制删除清单
- 删除 `modules/companion/claim.ts` 中的 `explicitClaimRequest()` 正则（`^记住/纠正/忘掉 <ULID>`）及 schema 强绑定；
- 删除 `runtime/studio/explicit-memory.ts` 与 `runtime/studio/teach.ts` 的正则前缀拦截分支；
- 删除 `runtime/studio/memory-gateway.ts` 中的 `memoryScopeFromMessage()`（`/^学习范围[：:]/` 解析）；
- **铁律**：仓库内禁止任何基于正则或关键词表从自然语言里抓取个性化数据的 Slop；所有语义抽取统一由 Agent 完成。

### 1.2 六大活动源 × 双轨个性化抽取流水线
学习者的每一次真实互动都是个性化数据的源头，Agent 必须覆盖全部 6 类活动源：

| 活动源 | Agent 抽取的核心信号 | 落库实体 | 触发轨道 |
|---|---|---|---|
| **1. 同伴对话** | 长期偏好、时间/作息/考试约束、讲解风格、口头暴露误解、短期状态（疲劳/焦虑/考试周，**必带绝对 `valid_until` TTL**）、自然语言“记住/改掉/忘掉” | `learner.preference` / `companion.claim` / `learner.misconception` | 轨 1（即时工具写）+ 轨 2（对话段结束异步深抽） |
| **2. 做题 / 整卷 / 后测 / 聊天检查** | 具体步骤级**稳定错因**（拒绝“粗心”等空标签）、解题习惯（跳步/漏单位/漏边界条件）、卡壳耗时分布、提示依赖模式 | `learner.misconception` / `companion.memoryAssertion` | 轨 2（交卷/判分后异步抽取） |
| **3. 拍卷与原件交入** | 手写风格、红笔习惯、常见涂改位置、边栏自注的易错提醒与解题思路 | `learner.preference` / `learner.misconception` | 轨 2（分层抽取后异步提炼） |
| **4. 活教材与笔记编辑** | 学习者自创口诀与成功理解路径、反复修改的薄弱块、块级标错指向的概念盲区 | `learner.playbook` / `companion.memoryAssertion` | 轨 2（保存修订后异步抽取） |
| **5. 学习型课堂与互动作品** | 哪种教学方法/脚手架/可视化真正促成从卡壳到独立做对（须经后续独立作答证实才晋升 `verified`） | `learner.playbook`（写入 `verified_playbooks`） | 轨 2（课堂归档 & 后测完成时） |
| **6. 隐式行为与负反馈** | 撤回后台复习单/讲义、拒绝某类推荐、连续跳过某活动、锁住或推迟某时段安排 | `learner.preference` / `Experience Ledger` | 轨 2（事件触发异步更新前哨与偏好） |

### 1.3 抽取质量、证据链与人机共治约束
1. **双轨协同**：
   - **轨 1（回合内即时）**：自然语言明确要求记住/修改/忘掉时，主 Agent 调 `save_memory`（按语义定位已有条目，绝不让用户抄 26 位 ULID），Tier 1–2 直落并返 `undo_token`。
   - **轨 2（全活动异步）**：通过 Temporal 异步增量工作流（受 `purpose` 与预算约束），将一批新产生的活动切片 + 相关已有画像摘要交给抽取 Agent（便宜/中档模型），输出严格的增/改/证伪操作。
2. **让 `memory-review` 真正运转**：异步抽取产出的 `supporting / contradicting` 证据自动挂载到对应 `MemoryAssertion`，触发 `modules/companion/derivers/memory-review.ts` 实时更新断言状态（确立 / 存疑 / 被反证退役），消灭“只有质检员没有生产者”的空转。
3. **强制证据锚定**：每条抽取必须带 `evidence_refs`（`fact_id + rev + excerpt`）；撤权或永久删除源活动时，依内核依赖自动失效，绝不泄露已撤权内容。
4. **防过拟合与粘性**：
   - 单次孤立失误或快答不得定性为长期习惯或能力缺陷，只能记弱观察；
   - 短期状态（如“今晚太累”）必须设置绝对失效时间（默认本次时段结束或当日 23:59 先到者），重启或跨日绝不自动续期；
   - 学习者在「我 → 它对我的理解」亲手修改、否定或删除的条目具有 `sticky` 粘性，后续异步抽取不得覆盖或复活。

## 2. 多维掌握度与自研遗忘模型（`modules/learner` + Python 推导器 Worker）

彻底淘汰当前 `modules/learner/retention.ts` 中仅面向单题原题（`same-item`）的 `lastIndependentResult` 规则原型，建设真正科学、可验证、可替换的自研认知与遗忘引擎。

### 2.1 独立 Python 推导器宿主（单元 6 正式落地）
- 在 `executors/python-deriver/` 建立跨语言 JSON 协议的纯计算 Python Worker（受控无外部状态、严格服从内核 `gather → derive` 输入清单与 fencing，不直接连数据库），用于承载自研遗忘模型、不确定性推断、信息量摸底选题与校准计算。
- TS 与 Python 共享版本化 Schema 与固定时钟确定性样例，确保可重放、可复现。

### 2.2 多维状态表达（非单一百分比）
能力与记忆状态不再坍缩为一个笼统分数，而是按 **`(knowledge_point / subskill, representation, context, method)`** 建模，输出结构化状态：
1. **掌握状态与不确定性**：
   - 连续估计值（如 `mastery_prob ∈ [0, 1]`）+ **不确定性区间/熵（`uncertainty`）**；
   - 未见过或证据不足时，显式返回 `state: "unknown"`（注明原因与需要何种新证据才能缩小不确定性），绝不伪造 50% 或 0%。
2. **自研读时遗忘 / 保持模型（非 FSRS）**：
   - 存储该学习者在该维度的**动态记忆状态向量**（如稳定性 `S`、提取难度/干扰度、历史间隔轨迹、跨变式迁移衰减参数），**不在午夜批跑刷数字**，而是在任意读取时刻 `t` 按 `elapsed(t)` 实时算出当前保持概率 `R(t)` 与未来 24–48h 跌破阈值的预计时刻 `predicted_crossing_at`；
   - 保持估计同时考虑：**题目新颖度**（原题重做 / 同构变式 / 陌生新情境分开权重，原题记忆绝不冒充跨情境迁移）与**帮助独立性**（看过提示或例题后的正确仅作弱证据，不直接等同独立掌握）。
   - **固定证据不漂移不变量（F37）**：在既有证据与标定参数不变的前提下，向题库新增未做过的题目绝不能导致已有掌握度判断漂移。
3. **结构化错因「病」档案（`learner.misconception`）**：
   - 每个活跃错因具备：清晰机理描述（定位到具体步骤/条件，如“分段行程漏算停车时间”）、关联知识点、支持证据列表、反证列表、当前状态（`active / improving / retired / relapsed`）；
   - 由新证据驱动状态跃迁（不硬编码“连续对 3 次就彻底治愈”），改善后复发自动回到 `relapsed` 并保留完整历史轨迹。

### 2.3 事前冻结预测、真实对账与 Shadow 重放（PRD §2.5 & §2.10）
- **凡预测必封存，凡封存必对账**：
  - 每次给出“下次做同类方向判断正确率约六成”、“某知识点 30 小时后将滑坡”或“本次模考总分区间 [78, 86]”时，必须先将预测（目标条件、方法版本、输入清单、置信/不确定性）落入 `predict.forecast` 槽位冻结；
  - 优先复用自然发生的后续独立作答/学校作业/独立后测进行对账（`predict.reconciliation`），严格区分 `matched / missed / observed / contaminated(受助污染) / awaiting-independent`；
  - 在「我」中透明展示：**样本量、可预测覆盖率、分桶校准误差（例如系统说六成把握时实际对了多少），并与简单基线（如近期同类平均正确率）同屏对比**。
- **Shadow 全历史重放与一键切换方法**：
  - 维护者（或研究流程）可挂载新的自研遗忘/掌握度推导器到同一槽位，在历史冻结输入上全量并行重放生成**不生效的 Shadow 候选**（严禁污染真实记录或触发采纳）；
  - 输出新旧方法在所有可对账事前预测上的对比报告（明确区分事前预测对账 vs 历史拟合），支持 1 处配置切换生效及随时切回，旧方法产出的历史推导永久可读可回溯。

### 2.4 双通道 Backtrace 与证据驱动的成长叙事
- **双通道 Backtrace**：给定当前错题或概念，同时跨越章节与教材检索两条真实线索：
  1. **相似错法通道**：该学习者过去在哪些题上犯过同类机理错误；
  2. **本人成功方法通道**：该学习者过去在哪些题上**曾独立做对过**类似结构（唤醒自信与可迁移脚手架）；
  - 每条结果均直达原题、原提交、原图与当时帮助记录；区分“系统推断”与“本人原话”，无匹配如实返回空。
- **成长叙事与同题前后对比**：所有成长总结必须引用真实前后证据，分开标注独立性、错步变化、用时与条件变化，拒绝用“刷了 50 题”冒充进步。

## 3. 本域禁止糊弄清单与硬验收矩阵

### 禁止糊弄清单
- ❌ 禁止保留任何 `^记住：`、`^纠正 <ULID>`、`^学习范围：` 等正则收取代码。
- ❌ 禁止以 `same-item` 二值规则（`lastIndependentResult`）冒充完整自研遗忘与多维掌握度引擎。
- ❌ 禁止给 `learner.misconception` 写“粗心”“基础不牢”“第五章不会”等泛化空标签。
- ❌ 禁止用单次快答或单次口误给学习者贴永久人格/风格标签（如“视觉型学习者”“爱乱猜”）。
- ❌ 禁止把受助正确、原题重做或本人自评混作独立迁移强证据。

### 硬验收矩阵
1. **正则 Slop 清零验收**：全仓代码检索确认零正则收取逻辑；用户在普通聊天说“我周六下午有球赛不学，以后物理别直接给公式先画图”→ Agent 无需任何前缀自动落库两条带原话证据与 `undo_token` 的结构化偏好/约束，并在次轮伴学与排期生效。
2. **跨活动异步抽取闭环**：完成“交卷错题 + 教材页写口诀 + 撤回一张复习单”后，异步抽取 Agent 自动产出结构化 `misconception`、`playbook` 候选与负反馈偏好，更新 `memoryAssertion` 经 `memory-review` 核验，全部进入 `memory-gateway` 并可在「我」页面点开证据与一键撤回。
3. **多维遗忘 + 信息量摸底 + Shadow 切换**：在真实隔离 PG + Python Worker 上，用同一学习者历史记录验证：（a）读时保持率随时间平滑衰减；（b）新增未答题旧掌握度零漂移；（c）原题受助做对不拉高陌生迁移预测；（d）对新旧两个遗忘推导器跑 Shadow 全历史对比并无损切换/回退。
4. **双通道 Backtrace**：跨章节同时找回本人历史同类错法与本人曾独立成功的解法，每条点击可打开原提交与当时帮助状态；撤回其中一条源记录用途后立即失效且不再泄露。
