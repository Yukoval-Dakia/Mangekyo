## 打印与撤权

打印红例在 `a3b8f10` 上实访。已授权及已撤权课堂的 `/classroom/:id/print` 都返回 SPA 200，但 main 为空；没有课堂 GET、写命令或 PDF。打印补丁之后，可从当前课、已结课和归档课的“打开打印版”进入同一路由。预览和实际打印均重新读取课堂与会话；浏览器的 beforeprint 在生成页面前同步复核，读取失败只输出不可读提示。[红例的请求与正文](print-gap.json) · [红例截图](print-gap-authorized.png)

Chrome 原生 Page.printToPDF 共输出 11 份样本，逐次核对前后 PostgreSQL teaching-model effect 计数相同，打印请求没有作品写命令。“打印或存为 PDF”按钮另行触发了浏览器 beforeprint。Poppler 抽取全部 PDF 文字并渲染归档样本：弹簧 PDF 包含矢量图、8 厘米、原观察和预测；断句 PDF 包含所选断点、原预测、作答回执和 100/100。打印补验另建的断句归档为 `5FC89484FB9E2BC2C82B9F2A18` rev 3，与前述正式旅程的 rev 5 分开。[弹簧归档 PDF](spring-archive.pdf) · [断句归档 PDF](passage-archive.pdf)

两份打印补验教材分别授权。撤销其中一份后，保持已经显示正文与图的标签，立即触发原生打印，再重新打开打印链接，另从普通课堂原生打印。撤源的弹簧图和断句内容在对应 PDF 中均消失，所有拒读样本的抽取文字只有“当前无法读取可打印的课堂。” 已合法输出到本地的历史文件属于当时的快照。[旧图页撤权后的 PDF](spring-open-tab-revoked.pdf) · [11 次输出的 SHA256、文本、浏览器请求与模型计数](printing.json)
